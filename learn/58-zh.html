我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

ConnorsRSI 给短期涨跌、连续涨跌天数和当天变化的罕见程度各打一个分，再取平均。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像三位老师分别评分，再合成一个 0 到 100 的成绩。

举个例子（虚构数字，只为讲解）

示例：连续多天上涨后读数达 95，说明近期动作很偏热；不代表明天一定跌。

先知道：为什么要看这个指标？

把短期涨跌力度、连涨连跌的持续性、当天变化相对历史的罕见程度放在一起，识别短期伸展。它是三个分数的平均，不是普通 RSI。

什么时候看它比较有意义

研究短期突然连续上涨或下跌是否已很偏激时使用；原始思路偏短期，不能把一次极端数值直接当成长线估值。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 ConnorsRSI 曲线
右轴通常 0 到 100，没有价格单位。一个读数混合短周期 RSI、连续方向天数的 RSI、涨跌变化的历史排名。
主图最近连续几根收盘
检查是否连续同向收盘，以及今天涨跌相对过去是否特别大；连续小涨也会影响分数，不只有巨量大阳线才会抬高。

第二步：看到变化，怎么读懂？

你看到：读数接近 90

这说明什么：三个短期维度合起来很靠上，可能已有较明显上伸。

还不能说明什么：不是 90% 概率明天跌。

你看到：读数接近 10

这说明什么：短期下行或连跌等维度合起来较极端。

还不能说明什么：不保证出现反弹，更不代表基本面便宜。

你看到：读数从 90 回到 55

这说明什么：短期极端程度缓和，可能因涨速放慢或连续状态改变。

还不能说明什么：不一定已经形成下跌趋势。

最容易看错的地方

不要把普通 RSI 的 30/70 直接当成 CRSI 的唯一标准。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构某天三个成分分别得 80、90、70 分，平均为 80；次日变成 60、40、50，平均为 50。

  1. 80 说明综合短期位置靠上，不是三个成分都一定为 80。
  2. 回到 50 可能是连涨结束或当天变化不再突出。
  3. 即使股价只从 110 回到 109，读数也可能明显降温，因为评分基于变化和排名。

把观察连起来，你可以这样说

它在说明短期状态是否伸展与降温，而非为价格设置必须反转的位置。

但不要跳到这个结论：不能用 80 与 50 的差算股价会跌 30%，也不能照搬普通 RSI 的解释。

最后试一题：你真的看懂了吗？

ConnorsRSI=5，能断言明天一定涨吗？

想好后，点开答案与解释

不能。它只说短期综合状态很低，强跌行情可继续低位；需继续看实际价格是否停止创新低。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Connors RSI

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 常见 RSI length 3、UpDown length 2、ROC length 100；0—100 坐标不等于普通 RSI 标准。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：康纳斯 RSI / Connors RSI

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：常见 RSI length 3、UpDown length 2、ROC length 100；0—100 坐标不等于普通 RSI 标准。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
