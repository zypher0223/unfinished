Linear Regression R² 回归决定系数

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

R² 看最近价格有多像一条直线。越接近 1 越整齐，越接近 0 越难用一条直线概括。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像问一排脚印排得直不直，不问它们朝哪边。

举个例子（虚构数字，只为讲解）

示例：一路整齐下跌也可以 R²=0.9；高数值完全可能是强下跌。

先知道：为什么要看这个指标？

检查用直线概括这段价格到底合不合适。R² 不是方向指标，而是价格围绕那条拟合直线有多整齐，能防止对杂乱数据过度相信趋势线。

什么时候看它比较有意义

你看到回归斜率或回归通道，想判断这条直线是否抓住了大部分变化时使用；它应和斜率配合，不能单独当强弱方向。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 R-Squared 曲线和右侧坐标
读数可能是 0 到 1，也可能乘 100 显示 0 到 100；0.8 与 80 是同一量级。它没有货币单位，是拟合解释程度。
主图同一回看窗口与拟合方向
看看 K 线是否大体排成一条斜带，还是上下散落；再查看斜率正负，R² 自己没有正负方向。

第二步：看到变化，怎么读懂？

你看到：R² 接近 0.9

这说明什么：这段价格相对像一条直线，拟合能解释较多变化。

还不能说明什么：不是未来预测有 90% 胜率。

你看到：R² 接近 0.1

这说明什么：简单直线对这段变化概括得不好。

还不能说明什么：不表示行情不能剧烈波动。

你看到：R² 升高而回归斜率为负

这说明什么：价格变得更整齐地向下走。

还不能说明什么：高 R² 绝不是上涨信号。

最容易看错的地方

R² 不是上涨概率，也不是模型预测正确率。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构两只价格路径：甲从 100 稳定降到 80，R²=0.92；乙在 80 至 110 间来回跳，最后回到 100，R²=0.08。

  1. 甲虽然跌，仍能被向下直线很好概括，所以 R² 高。
  2. 乙虽然曾涨到 110，变化却不是简单线性，所以 R² 低。
  3. 若甲突然反弹，多根新价格会改变窗口拟合，旧的 0.92 不能保证继续。

把观察连起来，你可以这样说

R² 评价的是描述工具的贴合程度，而不是涨跌好坏；高值必须与方向一起读。

但不要跳到这个结论：0.92 不是趋势永不结束的概率，也不能说明价格运动存在某种因果规律。

最后试一题：你真的看懂了吗？

R²=0.95，斜率为负，是强上涨吗？

想好后，点开答案与解释

不是，是这一窗口呈现较整齐的向下线性路径。高低只说明直线拟合好坏，方向由斜率提供。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

无可确认的唯一交易创始人 / No verified sole trading inventor

R² 是通用统计拟合指标；没有证据确认其首位交易使用者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。
