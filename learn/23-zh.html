Bollinger %B 布林百分比

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

%B只问收盘价在布林带哪儿：0是下轨，0.5是正中间，1是上轨。价格跑到轨道外，读数可以小于0或大于1。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像给道路左右边界标0和1，车开出路外时坐标也会超出边界。

举个例子（虚构数字，只为讲解）

计算示例：下轨90、上轨110、价格105，%B=(105−90)÷20=0.75。部分软件显示75%。

先知道：为什么要看这个指标？

布林%B把价格位于上下轨的哪里变成坐标：下轨是0，中间约0.5，上轨是1。它不是涨跌概率，也不是涨幅。超过上轨可大于1，跌到下轨外可小于0，所以不能把0与1当绝对边界。

什么时候看它比较有意义

想用一个数字快速比较价格在自身布林带的位置，或检查连续几根是否都贴着上轨时很有用。它需要和带宽配合：同样%B0.9，在很窄和很宽的带里，对应的实际价差可能很不同。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方Bollinger Bands %B窗及0、0.5、1参考
有的软件改显示0%、50%、100%，含义一致。读数0.75是从下轨往上走了带宽的75%，不是从买入价赚75%。
主图同参数上下轨和已收盘价
两图必须同周期同参数。将同一时点上下对齐，看看数字是否对应靠上或靠下；轨道移动也会使%B变化，不能只怪价格。

第二步：看到变化，怎么读懂？

你看到：%B持续接近1或超过1

这说明什么：价格靠近或位于近期上轨外，相对位置偏强。

还不能说明什么：不证明马上下跌或已不可能再涨。

你看到：%B在0附近或小于0

这说明什么：价格靠近或跌出下轨，相对位置偏弱。

还不能说明什么：不代表便宜到必须买。

你看到：%B从0.9回落至0.5

这说明什么：价格相对轨道向中间移动，可能价格回落，也可能中轨追上或带宽改变。

还不能说明什么：不能单看它认定绝对价格已经跌。

最容易看错的地方

%B=1不表示上涨概率100%；它只是位置，超出1也不代表立刻回来。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构下轨90、上轨110元，带宽20元，%B=(收盘−90)÷20。

  1. 收105得到0.75，位于带宽上部但未碰上轨。
  2. 收112得到1.1，超过1是合法读数，说明在上轨外2元。
  3. 若后来轨道变为100至120、价格仍112，%B变0.6；价格不跌，位置却明显下降。

把观察连起来，你可以这样说

%B是相对会移动的轨道的位置。数字下降时，要检查价格和两条轨道各自变化，避免把坐标变化当成绝对跌幅。

但不要跳到这个结论：1.1没有给出下跌概率110%，也没有证明价格必须回到0.5。

最后试一题：你真的看懂了吗？

%B等于0，是否表示价格归零、损失100%？

想好后，点开答案与解释

不是。0只是当前下轨的位置。例如下轨90、价格90，%B就是0，而价格仍90元。这个坐标与账户成本完全无关。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

John Bollinger

Bollinger本人官网明确说明他创建了%b，用来表示价格相对布林带的位置；首笔交易日期未核实。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Bollinger Bands %B

官方内置；%B与BandWidth是不同指标。 操作练习：添加Bollinger Bands %B，参数与主图BOLL一致。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：%B / BB%B / 布林百分比

独立入口未核验；有BOLL不等于一定有%B。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
