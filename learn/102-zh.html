CVD 累积成交量差值

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

把每根K线的成交差额放进同一个账本累计，观察一段时间内偏买方还是偏卖方的力量更持续。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

单根Delta是今天收支，CVD是从指定日期开始的累计余额。

举个例子（虚构数字，只为讲解）

仅作示例：三根差值+100、−40、+60，从0累计到100、60、120。

先知道：为什么要看这个指标？

累计成交量差额CVD把一根根差额记在同一本账上，看指定时间内正向还是负向活动更持续。单根Delta像今天的收支差额，CVD像从某日开始的累计余额。它累计的是被分类的成交量差，不是银行余额，不是净流入美元，也不是买家人数减卖家人数。先弄清真实逐笔分类还是小周期估算，才能知道这本账能说明多少。

什么时候看它比较有意义

你想比较价格一段时间的新高新低与累计活动是否同步时使用。锚定周期决定什么时候清零，例如每天或每周重新记账；不同重置方式得到的高低点不可直接混比。还应保持同交易所、品种、成交量单位和下级数据周期。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

副图累计曲线或CVD蜡烛与右侧刻度
位置是本次累计的数量，可正可负；上升代表新加入的差额偏正，下降代表偏负。蜡烛的开收和影线描述累计账在这一根内如何变化，不是资产价格。
清零时刻、前后分段及主图价格
找到本段从何时开始。新一段从零附近起算属于记账重置，不能直接与上一段尾值相减解释市场行为。对照主图时要对齐同一时间。

第二步：看到变化，怎么读懂？

你看到：同一累计段内价格和CVD都新高

这说明什么：价格与累计分类量在这段里同向增强。

还不能说明什么：不是随后仍会涨的承诺。

你看到：价格新高而CVD没新高

这说明什么：同段累计活动没有同步创纪录，形成不一致线索。

还不能说明什么：不证明已经见顶，数据估算和市场结构都可能影响结果。

你看到：跨日突然从大正值回到0

这说明什么：先检查是否到了日重置边界。

还不能说明什么：不能解释成所有资金突然离场。

最容易看错的地方

重置时从零开始不是资金突然出逃；它也不是全市场净流入金额。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构例子按每天重置，三根差额依次+100、−40、+60份。

  1. 账本从0走到100，再60，再120；第三根增60，不是又新增120。
  2. 第四根价格创日内新高，但差额−30，累计降到90，价格新高与CVD暂时不一致。
  3. 第二天新段从0开始，不能把昨天90到今天0当作卖出90份；今天自己的第一根差额才决定新账。

把观察连起来，你可以这样说

先在同一段里比较变化，再研究价格是否同步；分段边界必须先排除。

但不要跳到这个结论：不一致不保证反转，估算CVD也不是整个市场真实主动成交的完整账本。

最后试一题：你真的看懂了吗？

昨日CVD为1000，今日开头0，能说出现1000单位净抛售吗？

想好后，点开答案与解释

不能。若设置每天重置，这只是新账本从零开始。先确认重置时间，再计算本段每根差额；不跨账本拼接，才不会把软件规则误读成市场突然大量卖出。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

订单流累计方法；单一创始人未确认 / Accumulated order-flow measure

CVD把成交量差值逐根相加；未找到足够可靠资料确认概念的唯一首创和首用者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Cumulative Volume Delta

官方内置；Anchor period 决定累计何时归零。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：CVD / 累积成交量差值 / 累计Delta

仅为查找词；当前支持未确认，注意交易所、现货/合约及累计起点。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
