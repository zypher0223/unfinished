Bull/Bear Power 多空力量

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

Bull Power用最高价减EMA，Bear Power用最低价减EMA，看看一根K线能把价格推离平均线多远。有的软件分两条显示，有的相加成BBP。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

平均线像拔河中点，上端与下端告诉你两边分别能拉多远。

举个例子（虚构数字，只为讲解）

计算示例：EMA100、最高104、最低98，Bull=4，Bear=−2，若合并BBP则是2。

先知道：为什么要看这个指标？

Bull/Bear Power用最高价与最低价分别减同一条EMA，观察一根K线两端离近期平均有多远。Bull=最高−EMA，Bear=最低−EMA；有的显示两组，有的把它们相加成BBP。先弄清版本，才不会把合计当其中一边。

什么时候看它比较有意义

想知道上涨时最低价是否也逐渐抬到平均线上方，或下跌时最高价是否仍够不到平均线时很有用。它描述价格范围相对均价的位置，‘多空力量’是名字与解释角度，不是对真实买卖人数的测量。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方BBP或Elder-Ray窗与零线
读图例是Bull、Bear两组还是单一合计。值4表示与EMA相差4个价格单位，不是4%或4万人；零是等于EMA的位置。
主图同根最高、最低及EMA
蜡烛上影顶是最高、下影底是最低。两端都在EMA上方，Bear也可为正；两端都在下方，Bull也可为负，名字不规定正负。

第二步：看到变化，怎么读懂？

你看到：Bull正且增加，Bear由负接近0

这说明什么：上端离平均更远，下端也在靠近平均，整根价格范围可能抬高。

还不能说明什么：不证明买方人数增加。

你看到：Bull和Bear都负

这说明什么：整根最高最低都低于EMA，当前范围偏弱。

还不能说明什么：不表示没有买盘或未来必跌。

你看到：合计BBP为0

这说明什么：高低价相对EMA的距离相互抵消。

还不能说明什么：不等于没有波动，也不表示买卖双方金额相等。

最容易看错的地方

正数不是买方人数更多；指标只由价格推算，不知道真实账户数量。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构13期EMA100元，第一根最高104、最低98；第二根最高105、最低101；第三根最高99、最低95。

  1. 第一根Bull4、Bear−2，若合计BBP则为2；价格范围横跨EMA。
  2. 第二根若EMA仍100，Bull5、Bear1，连最低也在均线上，范围整体较强。
  3. 第三根若EMA仍100，Bull−1、Bear−5，连最高也在线下，合计−6。

把观察连起来，你可以这样说

先认每个值来自最高还是最低，再解释整根位置。合计会丢掉部分范围细节，所以两根不同形态也可能有同样合计。

但不要跳到这个结论：价格差值无法识别资金身份、委托数量或下一根方向，正值也不是自动开仓依据。

最后试一题：你真的看懂了吗？

EMA100、最高104、最低96，合计BBP为0，是否说明这根很平静？

想好后，点开答案与解释

不是。Bull4与Bear−4抵消，实际高低差有8元。合计接近0只说两端围绕均价相对对称，不能代替波动范围。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

Alexander Elder（Elder-Ray体系） / Alexander Elder (Elder-Ray)

多空力量与Elder的Elder-Ray体系相关；TradingView的BBP将Bull Power与Bear Power相加，不能把所有同名版本视为同一个公式。最早实盘使用未核实。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Bull Bear Power

官方内置BBP是两分量相加的版本。 操作练习：添加Bull Bear Power，先用13期。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：BBP / Bull Bear Power / 多空力量 / Elder Ray

可用性未核验；必须先看版本是否分开或合并。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
