WMA 加权均线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

WMA给最近一根价格最多的票数，越早的票越少，最后算一个加权平均价。常见的线性版本用1、2、3这样的权重。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

评选时昨天的表现算3票，前天算2票，再前一天算1票。

举个例子（虚构数字，只为讲解）

计算示例：价格10、11、12，权重1、2、3，WMA为(10×1+11×2+12×3)÷6≈11.33。

先知道：为什么要看这个指标？

WMA把最近N根价格按轻重求平均，常见线性版本让最新一根权重最大，越旧越轻。它和EMA都重视新数据，但权重安排不同。看它是为了把零散价格整理成近期方向，不需要把名字里的‘加权’理解成有更多内部消息。

什么时候看它比较有意义

想研究近期价格相对较早价格是否更强时，可用WMA观察。若拿它和SMA比较，要用同一资产、同一时间单位和同样根数；否则快慢差别可能只是参数不同，不能归功于算法更好。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主价格图中标记WMA的线
例如WMA20是一条价格线，读右侧相同的美元、元或USDT刻度。它通常不是下方0到100的打分线。图例中的20是根数。
线的连续方向与收盘价相对位置
先认同一时间点，再看最近几根有没有持续靠在线的一侧；同时查看窗口中是否有极端大涨跌拉动均值。

第二步：看到变化，怎么读懂？

你看到：WMA比同周期SMA高，且二者向上

这说明什么：较新的价格平均更高，给它们更多权重会抬高结果。

还不能说明什么：不是WMA发现了尚未发生的上涨。

你看到：WMA由上斜变平，价格贴近线

这说明什么：近期向上拉力变弱，平均值暂时没明显变化。

还不能说明什么：变平本身不确定下一步向下。

你看到：WMA向下、价格主要在下方

这说明什么：最新一段收盘整体偏弱。

还不能说明什么：不表示每根都跌，也不确定跌势能维持多久。

最容易看错的地方

不同软件的自定义加权方式可能不同；不能只看缩写就假定算法相同。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构3期线性WMA：三天收盘10、11、12元，旧到新权重1、2、3。

  1. 加权总数为10×1+11×2+12×3=68，权重合计6，所以WMA约11.33。
  2. 同三天SMA是11；WMA较高，因为最高的12是最新价格，得到最多权重。
  3. 下一天收9，窗口变11、12、9，WMA=(11+24+27)÷6≈10.33，明显转低。

把观察连起来，你可以这样说

最新大跌被赋予较大权重，使WMA较快降低。先理解这次转弯是已有收盘数据造成，再评估后续价格。

但不要跳到这个结论：一次更快转弯不等于能正确预测下一根；换一种加权公式也可能得到不同数值。

最后试一题：你真的看懂了吗？

一条WMA10比一条SMA50快，能证明加权算法一定优于简单平均吗？

想好后，点开答案与解释

不能。10根与50根本就覆盖不同时间。要研究权重影响，至少先统一根数、价格来源和图表周期，再比较转弯和反复误判。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

未确认唯一创始人 / No single inventor verified

加权平均是通用数学方法。John J. Murphy等作者讲解过WMA，但讲解者不等于最早发明者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Weighted Moving Average

官方内置WMA。 操作练习：添加Weighted Moving Average，先用20期收盘价。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：WMA / 加权均线

官方文档列有WMA。添加后演示设20期，确认是线性加权而不是EMA；入口随版本变化。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
