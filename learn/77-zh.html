Accumulation/Distribution 累积派发线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

ADL 看收盘位于当根范围的上半还是下半，乘成交量后累加。不是读取真实银行资金进出。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

每天净得分累加成总分。

举个例子（虚构数字，只为讲解）

示例：高 110、低 100、收 108、量 1000，位置系数 0.6，ADL 加 600。

先知道：为什么要看这个指标？

看成交量是否经常伴随着靠上端或靠下端的收盘，并把结果累积。ADL 用量价组合描绘持续偏向，不是实际银行资金流入流出。

什么时候看它比较有意义

价格创高但量价累计线没有呼应，或价格仍弱但累计线已改善时，作为进一步观察的线索；数据源成交量必须可信且一致。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图每根 K 线的收盘位置与成交量
收在当根高低范围上端，量被赋较正权重；收在下端赋较负权重，正中间约为零。量不是按今天比昨天涨跌来分。
下方 ADL 累计线
纵轴是加权成交量的累加，绝对起点依历史长度而变，没有真实资金金额含义。关注一段升降与峰谷，不跨交易所硬比总数。

第二步：看到变化，怎么读懂？

你看到：ADL 连续抬升

这说明什么：近期加权成交量偏向上端收盘的贡献较多。

还不能说明什么：不证明净资金正以同等数量流入。

你看到：价格涨但 ADL 走低

这说明什么：涨价过程中可能经常收在各根范围偏低处，需要检查结构。

还不能说明什么：不保证马上下跌。

你看到：ADL 近乎横向

这说明什么：正负贡献相抵，或收盘常在范围中间。

还不能说明什么：不代表市场没有成交。

最容易看错的地方

跳空下跌却收在当天高位，ADL 也可能上升。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构一根高 110、低 100、收 108、量 1000：位置系数=(108−100−(110−108))/10=0.6，ADL 增加 600。

  1. 收盘在上侧，因此这一根贡献正值。
  2. 即使前一天收盘 115、今天实际下跌，ADL 仍可增加 600，因为它看当根范围位置。
  3. 下一根若贡献 −400，两根净增加 200，但这不是流入 200 元。

把观察连起来，你可以这样说

ADL 的方向要按范围位置和成交量理解，不能直接当作每日涨跌或真实资本流。

但不要跳到这个结论：无法从这条线知道谁在买、谁在卖，更不能证明所谓主力吸筹。

最后试一题：你真的看懂了吗？

今天比昨天跌，但收在今天范围上端，ADL 可能上涨吗？

想好后，点开答案与解释

可能。它按当根高低范围中的收盘位置加权，不是按与昨日收盘的涨跌分配成交量。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Accumulation/Distribution

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 先确认成交量可用；ADL 为累计线，关注升降，不将其绝对值解释成真实资金。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：累积派发 / Accumulation/Distribution

AiCoin 官方专业K线文档列出此指标/系列；具体名称与参数入口依设备版本而异。 若找到对应实现：先确认成交量可用；ADL 为累计线，关注升降，不将其绝对值解释成真实资金。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
