Ichimoku 一目均衡表

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

一目均衡表用几条高低价中点线和一片云，把方向与可能卡住价格的区域放在同一张图里。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像一张天气图：云区表示眼前比较模糊，云上或云下更容易看清当前方向。

举个例子（虚构数字，只为讲解）

示例：价格处在云上且云也抬高，近期结构偏强；云画在右侧只是把旧数据前移，不是看见未来。

先知道：为什么要看这个指标？

用同一张图观察近期均衡位置、中期均衡位置和较宽的价格区域。云图把多个高低价中点放在一起，帮助说明价格站在哪一边，而非预测未来。

什么时候看它比较有意义

想从一张主图同时了解方向与可能反复争夺的区域时使用；先认识每个部件，再看它们是否讲出一致故事。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图的转换线和基准线
常用 9、26 根窗口的最高最低中点，纵轴与股票或币价相同；转换线较敏感，基准线较慢，并非成交均价。
先行 A、B 构成的云与迟行线
云由两条线之间填色形成，常向右移 26 根；迟行线是现在收盘向左移。右移图形是旧数据的排版位置，不是未来实测价格。

第二步：看到变化，怎么读懂？

你看到：K 线整体位于云上方

这说明什么：相对这套中点区域，价格位置偏强；再看基准线与实际高低点是否抬升。

还不能说明什么：云上也会发生急跌。

你看到：价格进入云内

这说明什么：价格处在两种均衡参考之间，方向较模糊，反复穿越更常见。

还不能说明什么：不表示一定反弹到云顶。

你看到：价格跌到云下，转换线也在基准线下

这说明什么：多个过去价格参照同时偏弱。

还不能说明什么：不保证下一根继续跌，也不是云在压住真实订单。

最容易看错的地方

未来位置的云不是未来价格预告；复杂线条越多不代表越准。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构日线：云范围 96 至 100，基准线 101，转换线 103，收盘从 105 回到 99。

  1. 105 时价格在云上，且高于两条中点线。
  2. 99 时已落入云内，也低于两条线，原来的强势排列被破坏。
  3. 如果图右方还有云延伸，那只是已算好的线被移到未来日期，那里尚无成交。

把观察连起来，你可以这样说

可说价格由偏强位置进入分歧区域，需要重新观察，而不是照搬先前云上结论。

但不要跳到这个结论：云的厚度不是亏损概率，也不证明 96 必然形成支撑。

最后试一题：你真的看懂了吗？

明天日期处显示一片上升云，是不是已经知道明天会涨？

想好后，点开答案与解释

不是。先行线把已知数据向右平移；它是未来日期上的参考区域，不是未来价格。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Ichimoku Cloud

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 先保留常见 9/26/52；主图云上偏强、云内模糊、云下偏弱，平移不是预测。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：一目均衡表 / Ichimoku Cloud

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：先保留常见 9/26/52；主图云上偏强、云内模糊、云下偏弱，平移不是预测。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
