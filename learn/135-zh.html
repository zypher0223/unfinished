Measured Moves 等距运动

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

定义等距运动（Measured Move）：把第一段走势（A 到 B）的价格幅度，从回调结束点 C 开始向同一方向复制一次，得到参考价 D = C + (B − A)（上涨）或 D = C − (A − B)（下跌）。D 只是观察参考，不是目标价承诺。

等距运动是一种量尺：第一段涨了多少，就从回调低点再量出同样的长度，看看价格到那里时会不会放慢。市场常走出接近的长度，但完全可能不到或超过。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像用第一步的步长，估计第二步大概落在哪里。

举个例子（虚构数字，只为讲解）

仅作示例：A=100，B=104，第一段涨 4；回调到 C=102，等距参考 D = 102 + 4 = 106。价格到 106 附近只是值得观察，不代表一定在那里停下。

是谁提出或推广的？

经典技术分析的测量法；Al Brooks 等系统讲解为“Leg 1 = Leg 2”

用前一段幅度推算参考位的方法见于早期图表分析教材；价格行为课程常把它称为等距运动。未确认唯一首创者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

打开后，按这几步看

  1. 标出第一段的起点 A 和终点 B，量出 B − A。
  2. 等回调结束，确认 C（回调低点，且没有跌破 A）。
  3. 从 C 加上同样的幅度，得到参考价 D。
  4. 价格接近 D 时观察是否放慢；若价格跌破 C，这次测量作废。

最容易看错的地方

把 D 当成必到的目标价是最常见的误解；它只是参考，价格可能提早掉头，也可能一路越过。
