Correlation Coefficient 相关系数

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

相关系数比较两种价格最近是否一起动：接近 +1 更同步，接近 -1 更反向，接近 0 不像有稳定的直线关系。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像两个人跳舞，观察是同方向走、反方向走，还是各跳各的。

举个例子（虚构数字，只为讲解）

示例：股票和指数最近的系数为 +0.8，只表示这段窗口较同步，不代表每天都一样涨。

先知道：为什么要看这个指标？

比较两个序列在过去窗口里是否一起升降。相关系数帮助识别表面不同的资产是否实际很同步，或者近期关系是否正在改变。

什么时候看它比较有意义

同时观察两种股票或币，想知道过去是不是常一起动时使用；用于分散风险思考时还要注意，它比较的是所选价格或数据源，不自动等于收益率相关性。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 Correlation Coefficient 曲线
先确认两边标的、价格源、周期与窗口相同；纵轴从 −1 到 +1，零是无线性相关参考，数值没有价格单位。
主图及第二标的对应时间段
看同一日期的变化，不能把不同交易时段硬拼。默认若比较收盘价格，读到的是价格序列相关，不应擅自称为日收益率相关。

第二步：看到变化，怎么读懂？

你看到：系数接近 +0.9

这说明什么：该窗口两序列有较强同向线性关系。

还不能说明什么：不表示一方涨 1%，另一方必涨 0.9%。

你看到：系数接近 −0.8

这说明什么：该窗口倾向反向变化。

还不能说明什么：不保证未来能稳定对冲，也不说明谁导致谁。

你看到：系数在 0 附近

这说明什么：该窗口没有明显线性关系。

还不能说明什么：不证明它们完全独立，仍可能有其他非线性联系。

最容易看错的地方

相关不等于因果；价格水平的相关也不等于收益率相关。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构两资产用相同日线收盘、30 根窗口计算：上个月系数 +0.85，这个月降到 +0.15。

  1. 旧窗口两条价格序列走势较同步。
  2. 新窗口同步的线性程度明显减弱。
  3. 若你关心每日盈亏是否同步，应另外比较日收益率序列，而非把价格系数直接代用。

把观察连起来，你可以这样说

能说明观察口径下的历史联系在变化，不能把资产关系当作永远固定。

但不要跳到这个结论：+0.85 不是因果证据，也不是持有两者一定亏赚同步的保证。

最后试一题：你真的看懂了吗？

相关系数 −0.7 能证明甲上涨会导致乙下跌吗？

想好后，点开答案与解释

不能。它只描述该窗口的反向线性关系；共同因素、样本选择或偶然性都可能造成这种关系。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

统计方法，未确认首位交易使用者 / Statistical method; first trading user unverified

此处是通常所称的 Pearson 型相关系数；官方未指定将其首用于交易的个人。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Correlation Coefficient

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 在 Inputs 的 Symbol 填第二个标的；Length 是比较窗口，先保留默认 Source Close。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：相关系数 / Correlation Coefficient

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：在 Inputs 的 Symbol 填第二个标的；Length 是比较窗口，先保留默认 Source Close。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
