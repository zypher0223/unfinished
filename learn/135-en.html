Measured Moves

My learning & reviewBeginner route

Records are saved only in this browser. Reading is not the same as mastery.

A measured move is a ruler: take how far the first leg went and measure the same distance again from the pullback low, then watch whether price slows when it gets there. Markets often travel a similar distance, but they can fall short or overshoot.

DefinitionA measured move copies the price distance of the first leg (A to B) from the end of the pullback C in the same direction, giving a reference level D = C + (B − A) for a rise, or D = C − (A − B) for a fall. D is only a reference for observation, not a promised target.
First chart ever? Read these four ideas first
Price chart and candle
A candle summarizes one chosen time interval. On a daily chart, each candle is one day; it shows the opening, highest, lowest and closing price for that day.
Length or period
A length of 14 usually means 14 candles, not automatically 14 days. On a one-hour chart that means 14 hours of bars.
Main chart and lower pane
The main chart shows price. A lower pane is a separate little chart below it. Its numbers may use completely different units.
Signal
A signal is a condition worth checking, such as one line crossing another. It is an observation, not a guarantee or an automatic order.

Think of it this way

Like using the length of your first stride to guess where the second will land.

A made-up example

Illustration only: A=100 and B=104, so the first leg is 4. After a pullback to C=102, the measured-move reference is D = 102 + 4 = 106. Reaching about 106 is only worth watching; it does not mean price must stop there.

Who developed or popularized it?

Classical measuring technique; taught by Al Brooks and others as “leg 1 = leg 2”

Projecting a prior leg’s distance appears in early charting texts; price-action courses usually call it a measured move. No single originator verified.

An attributed developer, popularizer and first user are different claims. A unique first user is stated only when reliable documentation supports it.

Read it one step at a time

  1. Mark the first leg’s start A and end B, and measure B − A.
  2. Wait for the pullback to end and confirm C (the pullback low, above A).
  3. Add the same distance to C to get the reference level D.
  4. Watch whether price slows near D; if price breaks below C, the measurement is void.

The mistake to avoid

The most common mistake is treating D as a guaranteed target. It is only a reference; price may turn early or run straight through it.
