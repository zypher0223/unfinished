Point & Figure Charts

My learning & reviewBeginner routeLesson quiz

Records are saved only in this browser. Reading is not the same as mastery.

Point and figure is one of the oldest ways to record price: one X per box up, one O per box down, and a new column only after a reversal of three boxes. It cares how far price moved, not how long it took, which makes breakouts and support/resistance easy to see.

DefinitionA point and figure chart records rises as columns of X and declines as columns of O, each box worth a fixed price amount (the box size). Each full box travelled in the current direction adds a symbol; a move of the set number of boxes the other way (commonly three) starts a new column. There is no time axis; signals such as the “double top breakout” (an X column exceeding the prior X column’s high) are common.
First chart ever? Read these four ideas first
Price chart and candle
A candle summarizes one chosen time interval. On a daily chart, each candle is one day; it shows the opening, highest, lowest and closing price for that day.
Length or period
A length of 14 usually means 14 candles, not automatically 14 days. On a one-hour chart that means 14 hours of bars.
Main chart and lower pane
The main chart shows price. A lower pane is a separate little chart below it. Its numbers may use completely different units.
Signal
A signal is a condition worth checking, such as one line crossing another. It is an observation, not a guarantee or an automatic order.

Think of it this way

Like bookkeeping on graph paper: you only write an entry when the amount changes by a full box, and time is not recorded.

Who developed or popularized it?

Late-19th-century “figure chart” bookkeeping tradition; specific inventor unverified

Point and figure grew out of late-19th-century traders’ hand-recorded price columns; Victor de Villiers’s 1933 book and A. W. Cohen, among others, popularised it. The earliest inventor is unverified.

An attributed developer, popularizer and first user are different claims. A unique first user is stated only when reliable documentation supports it.

Read it one step at a time

  1. Choose the box size and reversal amount (commonly three boxes) and record them.
  2. Add a symbol for each full box in the current direction; partial boxes are not recorded.
  3. Switch columns only after the set reversal.
  4. Watch for an X column exceeding the prior X column’s high (a breakout), and check timing on normal candles.

The mistake to avoid

Changing the box size or reversal amount but keeping the same conclusions is a common error; different settings give completely different signals.
