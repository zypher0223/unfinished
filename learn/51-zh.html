McGinley Dynamic 麦金利动态线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

麦金利动态线也是一条跟着价格走的平均线，只是公式会根据价格与线之间的关系自动调整追赶速度。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像一根有弹性的牵引绳，想在快慢变化时更贴近前方的人。

举个例子（虚构数字，只为讲解）

示例：价格突然从 100 升到 105，动态线会调整，但不会提前知道跳涨。

先知道：为什么要看这个指标？

用一条追赶速度会随价格关系调整的动态线，看价格的大致方向和偏离程度。它尝试改善固定均线的某些滞后，不能免除所有滞后。

什么时候看它比较有意义

想用单线简化主图，同时观察价格偏离后参考线如何追赶时使用；急涨急跌和盘整都要分别看，不能只挑好看的历史段。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图的 McGinley Dynamic 曲线
右轴数字与股票或币的报价同单位；它是公式递推出来的动态价格参考，不是资金成本或真实挂单位置。
K 线收盘与曲线的距离、曲线朝向
读距离时用实际价差或百分比，不用屏幕厘米；调大缩放会让同样价差看起来更陡，但不会改变数据。

第二步：看到变化，怎么读懂？

你看到：曲线上行，连续收盘位于线上

这说明什么：历史平滑方向与当前价格位置一致偏上。

还不能说明什么：不保证线能托住下一次回落。

你看到：价格在线两侧频繁交换，线趋平

这说明什么：当前窗口的方向不清楚，交叉易受小波动影响。

还不能说明什么：不表示每次交叉都值得交易。

你看到：价格急跌到线下，曲线还没明显转向

这说明什么：新变化快于递推线的反应。

还不能说明什么：不能因为指标慢就说跌价无效。

最容易看错的地方

不要把宣传中的减少滞后理解成没有滞后；横盘仍会多次穿线。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构日线：动态线从 98 升到 102，价格从 100 升到 106；随后价格一根跌到 97，线仍约 101。

  1. 前段价格和线同时抬升，说明过去方向一致。
  2. 急跌后价格已明显低于线，原先线上状态被破坏。
  3. 如果后续回到 102，不能仅用一次重新上穿判断趋势恢复，还应看高低点是否重新抬升。

把观察连起来，你可以这样说

动态调速让参考线更适应部分行情，但阅读顺序仍是先实际价格，再历史平滑背景。

但不要跳到这个结论：价格在线上不等于所有持有人盈利，跌破也不证明机构撤退。

最后试一题：你真的看懂了吗？

价格在 99 至 101 间反复穿越 100 附近的动态线，你能确认新趋势吗？

想好后，点开答案与解释

不能。两侧切换说明净方向弱，要看是否有持续推进，而不是把穿线次数当作趋势证据。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：McGinley Dynamic

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 保留默认周期，在主图比较价格与动态线；本线仍会落后于急转弯。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：麦金利动态线 / McGinley Dynamic

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：保留默认周期，在主图比较价格与动态线；本线仍会落后于急转弯。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
