Darvas Box 箱体理论

我的学习与错题新手路线课后小测

记录仅保存在当前浏览器；已读不等于已经掌握。

达瓦斯箱体是一套给上涨中的整理画框的规则：新高之后停下来，就把这段停顿框起来；价格突破框顶，就换一个更高的框。它把“趋势中的台阶”变成了可执行的规则。

定义达瓦斯箱体：价格创出新高后，若接下来连续 3 根K线都没有超过这个高点，该高点就是箱顶；箱顶确认后，若随后出现一个低点且接下来连续 3 根都没有跌破它，该低点就是箱底。收盘越过箱顶为向上突破，开始画新的箱子；跌破箱底则箱体失效。
第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像楼梯的每一级平台：走到平台上歇一下，再往上走一级。

举个例子（虚构数字，只为讲解）

仅作示例：价格创新高 105.0，之后 3 根最高 104.8、104.6、104.9，都没超过，箱顶 = 105.0；之后低点 103.6，接下来 3 根都没跌破，箱底 = 103.6。收盘越过 105.0 为突破。

是谁提出或推广的？

Nicolas Darvas

舞蹈家 Nicolas Darvas 在 1960 年出版的《How I Made $2,000,000 in the Stock Market》中介绍了这套方法；书名中的收益是作者自述，本课不作核实。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

打开后，按这几步看

  1. 在上涨中找新高，看接下来 3 根是否都没超过它，确定箱顶。
  2. 箱顶确定后找低点，看接下来 3 根是否都没跌破，确定箱底。
  3. 收盘越过箱顶，记为突破，按同样规则画下一个箱子。
  4. 收盘跌破箱底，箱体失效。

最容易看错的地方

不按规则随手画框，或在箱顶还没确认时就“预判突破”，会让箱体失去意义。
