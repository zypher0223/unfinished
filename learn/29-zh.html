ADR 平均每日振幅

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

ADR算过去几天每天最高价减最低价的平均值。与ATR不同，它通常不把昨收与今开之间的跳空另算进去。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

记录每天在院子里走动的最远两点距离，再求平均。

举个例子（虚构数字，只为讲解）

计算示例：3天日内高低差分别4、6、5元，3日ADR=5元。

先知道：为什么要看这个指标？

ADR算过去若干天各自最高减最低，再求平均，描述‘一天内部通常走开多大距离’。它通常不另计昨收至今开的跳空，所以与ATR不同。理解它能为今天高低范围提供参照，但均值不是每天必走完的任务量。

什么时候看它比较有意义

想知道今天日内范围相较过去是安静还是突出时，可用ADR。股票有隔夜跳空时，尤其要同时看ATR或昨收；否则看似很小的日内范围可能掩盖很大的隔夜变化。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

标ADR的下方曲线或图上数值标签
14日ADR5表示过去14天日内高低差平均约5个报价单位，不是5%。有变体按百分比展示，需看标签；非日线输入不应随口称每日范围。
今天主图最高、最低与日界线
量出今日最高减最低，再和ADR比较。在小周期图要先识别同一交易日，确认指标仍按日数据计算，别把14根5分钟误认14天。

第二步：看到变化，怎么读懂？

你看到：今天已走范围远小于ADR

这说明什么：截至此刻日内活动比历史均值小，可能仍早或较安静。

还不能说明什么：不意味着之后必须补足剩余距离。

你看到：今天范围已超过ADR

这说明什么：当天日内活动比平均大。

还不能说明什么：不保证会停止，更不是确定反转点。

你看到：ADR持续下降但隔夜跳空很大

这说明什么：日内变安静不代表全部价格风险降低。

还不能说明什么：不能用ADR下降否认隔夜风险。

最容易看错的地方

今天已走出一倍ADR不代表一定停止；平均值不是上限。非日线计算不能随口叫每日振幅。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构最近三天日内高低分别104/100、108/102、110/105元，差值4、6、5，所以3日ADR=5。

  1. 今天最高113、最低110，已走3元，小于均值5。
  2. 即使昨收100、今天开110，这10元跳空也不在今天的高低差3里。
  3. 下午最低落到106，今日范围扩成7元，超过ADR；均值不会把价格挡在5元处。

把观察连起来，你可以这样说

ADR描述日内区间大小，不能代替从昨收起的全部变化；超过平均只说活跃程度突出。

但不要跳到这个结论：不知道下午还会走多远，也不能推导反向买卖必能赚钱。

最后试一题：你真的看懂了吗？

ADR5，今天已经走5元，能断言剩余时间不会再创新高或新低吗？

想好后，点开答案与解释

不能。平均只是历史参照，没有限幅功能。今天可能走2元也可能走15元；把均值当硬边界会误解指标目的。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Average Daily Range

官方内置ADR；若在小周期使用，务必核对计算Timeframe。 操作练习：添加Average Daily Range，先切日线并设14期，确保读的是每天。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：ADR / 平均每日振幅

独立入口未核验；不要误选上涨/下跌家数比的同缩写指标。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
