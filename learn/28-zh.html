ATRP/NATR 百分比波幅

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

把ATR换成占价格的百分比，方便比较不同价位资产。100元股票动2元和10000元币动200元，都是约2%。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

比较大小不同的人的负重，先换成体重的百分比。

举个例子（虚构数字，只为讲解）

计算示例：收盘100、ATR2，ATRP=2%；收盘1000、ATR20，同样是2%。

先知道：为什么要看这个指标？

ATRP/NATR常把ATR除以收盘价再乘100，回答‘通常的单根活动相当于价格的百分之几’。它把高价与低价资产放到较可比的比例尺度，而不是让几元与几百元的绝对幅度误导你。

什么时候看它比较有意义

需要比较不同价格资产的相对波幅，或同一资产价格翻倍后波动是否真的更剧烈时有用。先统一时间单位、ATR长度和平滑方式；有些脚本先逐根归一再平均，不能只看同名就认定公式相同。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方NATR或ATRP窗口的百分比刻度
标准ATR÷收盘版读2表示2%；若脚本画0.02则是小数比例。它不是价格2元，也不是未来收益2%。先读脚本说明确认算法与单位。
同时间ATR读数和主图收盘价
将两者相除可以核对。日线的2%描述日线根，5分钟的2%是另一种尺度；不要用不同周期数值直接排名。

第二步：看到变化，怎么读懂？

你看到：同一资产ATRP上升

这说明什么：平均真实活动占当前价格的比例变大。

还不能说明什么：不表示价格上涨，价格下降也会使分母变小。

你看到：两个资产同周期ATRP都为2%

这说明什么：按该算法，单根平均活动相对价格尺度近似。

还不能说明什么：不代表跳空、流动性、杠杆风险都一样。

你看到：ATR不变而ATRP下降

这说明什么：可能价格升高，使相同绝对活动占比变小。

还不能说明什么：不一定每根实际活动都在收缩。

最容易看错的地方

同名变体的计算次序可能不同；2%不是下一根一定波动2%，也不是收益率。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构A收100元、14日ATR2；B收1000元、同算法ATR20。

  1. A的ATRP=2÷100×100=2%；B为20÷1000×100=2%，绝对数虽差十倍，占比相同。
  2. A后来价格跌到80、ATR仍2，ATRP增至2.5%。
  3. 此时升高既来自价格分母变小，不必有新的更大绝对波动。

把观察连起来，你可以这样说

比较比例有意义，但还要拆开ATR和价格，解释变化来自哪里；参数与周期一致才有基本可比性。

但不要跳到这个结论：2%不是下一日必动2%，也不是拿同样金额就保证承受完全相同损失。

最后试一题：你真的看懂了吗？

A日线ATRP1%，B一分钟ATRP1%，能说两者每天同样剧烈吗？

想好后，点开答案与解释

不能。一根代表的时间完全不同。先统一为日线且核对算法，再讨论相对波幅；分钟活动不能不加条件直接当日活动。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

ATR由Wilder提出；百分比变体首创者未确认 / ATR by Wilder; percentage variant inventor unverified

ATRP/NATR把ATR按价格归一化，常见公式是ATR÷收盘价×100；不能据ATR来源推断所有变体均由Wilder首创。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Normalized Average True Range / ATRP / NATR

本次仅确认官方筛选器有ATR%及社区NATR脚本，不保证图表有同名官方内置。 操作练习：先读懂ATR，再查看脚本的NATR/ATRP公式。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：NATR / ATRP / 百分比波幅

独立入口未核验；可用ATR÷收盘价×100手工理解示例，不代表软件已内置。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
