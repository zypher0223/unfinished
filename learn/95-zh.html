Pivot Points High/Low 高低点枢轴

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

等一个位置两边都出现较低的高点，才把它认作局部高点；低点反过来。它帮你把小山峰和小山谷标出来。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

山峰必须看到另一边也往下走，才能确认它真是峰顶。

举个例子（虚构数字，只为讲解）

仅作示例：左右各看2根，周三最高价超过前后各2天，周五收盘后才能确认周三的峰。

先知道：为什么要看这个指标？

局部高低点指标把一段价格里的小山峰和小山谷标出来。所谓高点，是这根最高价高于左边指定数量、也符合右边指定数量的比较条件；低点反过来。关键在右边：必须等后续K线出来，才能确认前面那根是不是山峰。它用来整理走势结构，不是提前知道最高最低的机器。

什么时候看它比较有意义

适合练习比较已确认的高低点：后一个高点和低点有没有抬高，还是同时降低。它不适合看见历史箭头就假设当时能在箭头处成交。先固定左右各几根，以及相等高低价如何处理，避免不同脚本规则混用。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图K线上下的点、箭头或价格标签
高点标记对应那根的最高价，低点对应最低价，单位仍是价格。标记经常画回发生转折的旧K线上；横坐标是转折发生时间，不一定是信息可获得时间。
标记右侧用于确认的K线
假设右长度为2，至少要等右侧两根完成。把确认时刻也标出来，才能知道当时实际能看到什么。正在形成的最新位置不是同等确定的点。

第二步：看到变化，怎么读懂？

你看到：已确认高点与低点都逐步抬高

这说明什么：按这组过滤尺度，历史价格结构偏向上行。

还不能说明什么：不保证下一个低点仍抬高，更不代表所有更小周期也向上。

你看到：已确认高低点都降低

这说明什么：该尺度下历史结构偏向下行。

还不能说明什么：不是标记一出现价格就必须继续跌。

你看到：刚出现高价但右侧根数不足

这说明什么：它只是候选高点，还不能完成比较。

还不能说明什么：不能把后来补出的标记冒充当时已知。

最容易看错的地方

回看很漂亮的顶底标记有确认延迟；最新高低点仍可能没有确认。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构日线，左右各2根，周一到周五最高价依次为10、11、13、12、11。

  1. 周三到13时，只知道它高于周一周二；周四仍可能涨到14，因此当时不能确认。
  2. 周五结束后，右侧12和11都低于13，周三的13才被确认为局部高点。
  3. 标记可能显示在周三，但实际最早周五完成后可知；若价格已跌到11，不能假设自己还能卖在13。

把观察连起来，你可以这样说

转折发生位置与确认发生时间不同，学习结构时必须同时记这两个时间。

但不要跳到这个结论：一个局部高点不等于长期顶部，确认延迟也不能消除后续价格变化。

最后试一题：你真的看懂了吗？

右长度3的高点箭头画在昨天，昨天就能据此卖出吗？

想好后，点开答案与解释

不能。右侧三根必须出现并完成比较，箭头才可能确定；历史图把结果放回过去，容易造成提前知道的错觉。练习时要用回放观察信息何时真正出现。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

通用局部高低点算法；单一创始人未确认 / Generic local-extreme algorithm

这不是标准枢轴点公式，而是左右比较K线来确认高低点的通用算法；未确认首创者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Pivot Points High Low

官方示例指标；留意左右确认长度与标记回画。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：高低点枢轴 / Pivot High Low

仅为查找词；内置支持未确认，需检查是否有右侧确认延迟。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
