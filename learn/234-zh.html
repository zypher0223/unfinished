On-Chain Data Basics 链上数据入门：区块浏览器、地址与资金流向

我的学习与错题新手路线课后小测

记录仅保存在当前浏览器；已读不等于已经掌握。

以太坊上的一笔交易会记下发送方（from）、接收方（to）、金额（value）、序号（nonce）和手续费（gas，执行交易要付的费用）等字段，并广播给全网，所以人人可查。区块浏览器是“查账工具”，不是钱包，它不保管你的私钥，也不能替你撤回转账。浏览器和数据公司会给一些地址贴“标签”，比如“某交易所热钱包”“巨鲸”（持有大量资产的地址），这些标签是他们根据线索做的推断，可能出错。看资金流向时还要注意：转入交易所不等于要卖出，交易所自己在冷钱包（离线保存）和热钱包（在线、用于日常提现）之间调拨，也会产生大额转账。

定义链上数据是公链上公开记录的交易、地址余额和合约调用。任何人都可以用区块浏览器（如 Etherscan）逐笔查看，也可以用数据平台（如 Dune，用 SQL 查询汇总）做成看板。常见用途：核对一笔转账是否成功、查看一个地址持有什么、观察大额资金在交易所地址之间怎样流动。
第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

链上数据像一面公开的银行流水墙：每一笔进出都贴在墙上，但账户名是一串编号；旁边有人用便利贴写着“这是某某的账户”，那只是他的猜测。

举个例子（虚构数字，只为讲解）

仅作示例：一个被标为“交易所热钱包”的地址一天内收到 5 笔、共 3,000 ETH 的转入。按 1 ETH = 2,000 美元（仅作示例）算，3,000 × 2,000 = 6,000,000 美元。这可能是用户准备卖出，也可能是交易所在调拨，或做市商补充库存，单看这个数字分不出来。再查同一时段：该交易所的冷钱包是否转出了 3,000 ETH 到这个热钱包？如果是，净流入 = 3,000 − 3,000 = 0，这多半是内部调拨，不代表外部资金进场。

是谁提出或推广的？

没有单一发明人：区块浏览器和链上分析随公链的公开账本出现

公链的交易要广播给全网验证，记录天然公开；区块浏览器把这些记录整理成网页，数据平台再把它们整理成可以用 SQL 查询的表。地址标签由各家公司自行维护，口径不统一。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

打开后，按这几步看

  1. 核对转账：把交易哈希（TxHash，每笔交易的编号）粘到区块浏览器，先看状态是成功还是失败，再看 from、to、金额、代币种类和所在网络。
  2. 看地址页：余额、代币持仓和交易记录都在这里；地址旁的标签来自浏览器或数据公司，当作线索而不是事实。
  3. 看资金流向：把同一机构的多个地址合起来算净额，先排除内部调拨，再谈外部资金进出。
  4. 用现成看板时：打开查询看口径——包含哪些链、哪些地址、什么时间段；两个看板数字不同，多半是口径不同。

最容易看错的地方

把“大额转入交易所”直接读成“要大量卖出”，或把浏览器上的地址标签当成确定的身份。前者常常只是内部调拨，后者只是第三方的推断。
