Linear Regression Channel 回归通道

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

回归通道在最贴近近期价格的直线上下各画一条边线，让你看到价格偏离近期中心有多远。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像道路中心线与两侧护栏，但价格可以穿过护栏。

举个例子（虚构数字，只为讲解）

示例：中心线在 100，上轨 104，下轨 96。价格到 105 只表示偏离较大，不保证回到 100。

先知道：为什么要看这个指标？

把近期价格大方向和离中心的远近分开看。回归通道用中线概括趋势，用上下边线表示围绕中线的波动范围，方便比较位置。

什么时候看它比较有意义

想判断价格是在近期轨迹中间还是明显偏边，并检查趋势有没有变形时使用；通道适合描述选定窗口，不能自动预测下一窗口。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图的回归中线与上下平行边线
中线是对近期价格拟合的直线，边线常按标准差倍数展开，右轴都是价格。先看所用根数和偏差倍数，再比较通道宽窄。
最新收盘在通道中的位置
看中线斜率确定历史方向，看收盘离中线、上边、下边哪个近；窗口滚动后整组线可能重算，不能把后来图形当当时已知。

第二步：看到变化，怎么读懂？

你看到：通道向上，价格靠近上边

这说明什么：价格位于近期向上轨迹的较高一侧。

还不能说明什么：不保证马上跌回中线。

你看到：通道向下，价格靠近下边

这说明什么：价格位于近期向下轨迹的较低一侧。

还不能说明什么：不代表便宜或必然反弹。

你看到：价格连续跑到通道外

这说明什么：当前移动已偏离该窗口的常见范围，应检查趋势或波动是否改变。

还不能说明什么：边线不是阻止成交的墙，也不保证外侧都是错误报价。

最容易看错的地方

通道会随新价格重算；越过边缘不等于一定反转。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构 100 根日线拟合：当前中线 100、上边 110、下边 90，中线向上；最新收盘 108。

  1. 108 比中线高 8，离上边仅 2，位置偏上。
  2. 次日收盘 113，说明走到旧通道外，可能是加速也可能是短暂异常。
  3. 继续观察后续收盘与重算后的通道，才能知道偏离是否持续。

把观察连起来，你可以这样说

结论只是价格处于原有轨迹高侧并发生超出，不是直接给出反向交易理由。

但不要跳到这个结论：所谓两倍标准差不自动保证金融价格有固定 95% 的覆盖概率。

最后试一题：你真的看懂了吗？

价格碰到上边线就必须卖吗？

想好后，点开答案与解释

不必须。趋势加速时可沿上边甚至越界运行；通道说明相对位置，不能保证均值回归。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

无可确认的唯一交易创始人 / No verified sole trading inventor

回归通道来自通用统计回归加上下轨；未查到足以确认首位交易使用者的资料。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Linear Regression

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 内置搜索名称为 Linear Regression；Count 控制回看 K 线数量，上下 Deviation 控制通道宽度。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：回归通道 / Linear Regression

未核实 AiCoin 有同名回归通道。先搜索并核对公式；若提供长度或回看数量，它控制取多少根历史 K 线；若有偏差倍数，它控制通道宽度。不要把普通平行通道当成自动回归通道。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
