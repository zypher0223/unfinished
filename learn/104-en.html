Advance/Decline

My learning & reviewBeginner route

Records are saved only in this browser. Reading is not the same as mastery.

The Advance/Decline Line adds each day's advancing-stock count minus declining-stock count to a running total. It shows how broadly a market move is shared.

First chart ever? Read these four ideas first
Price chart and candle
A candle summarizes one chosen time interval. On a daily chart, each candle is one day; it shows the opening, highest, lowest and closing price for that day.
Length or period
A length of 14 usually means 14 candles, not automatically 14 days. On a one-hour chart that means 14 hours of bars.
Main chart and lower pane
The main chart shows price. A lower pane is a separate little chart below it. Its numbers may use completely different units.
Signal
A signal is a condition worth checking, such as one line crossing another. It is an observation, not a guarantee or an automatic order.

Who developed or popularized it?

1930年代市场广度实践；Richard Russell（推广）

TradingView records use in the 1930s and popularization through Richard Russell's Dow Theory Letters in the 1960s. Secondary sources say Leonard P. Ayres of Cleveland Trust analyzed advance-decline data as early as 1926 and Barron's published the figures from 1931; a sole inventor is still not firmly established.

An attributed developer, popularizer and first user are different claims. A unique first user is stated only when reliable documentation supports it.

Read it one step at a time

  1. Identify the exchange or stock universe being counted.
  2. Compare it with an index covering the same market.
  3. Note when the index makes new highs but the line does not.
  4. Study the trend over time instead of one day's count.

The mistake to avoid

This is not a count of green and red candles on one stock. Universe and delisting treatment affect history.

Where to find it: TradingView & AICoin

These paths describe desktop web charts, checked against official help on 19 October 2026. App layouts and account/data permissions can differ.

TradingView

Search terms：Advance Decline Line

Official documentation exists; verify the underlying breadth market and avoid confusing it with Advance/Decline Ratio (Bars).

  1. Open the TradingView chart using the button below. Choose a stock or coin at the upper left and check the exchange. Choose a chart interval, for example 1 hour or 1 day; one daily candle represents one day.
  2. Use Indicators in the upper chart toolbar, then enter one of the search terms below. Check built-in Technicals first. Community scripts with similar names may calculate different things.
  3. Select the matching result to add it, close the search, and look for a new line or lower pane. If there is no exact built-in match, read the availability note rather than substituting a different indicator.
  4. Hover over the added indicator name and open Settings. Inputs changes calculation settings such as length; start with the defaults. Style changes visual appearance. Follow this lesson’s interpretation steps.
  5. Review completed historical candles and explain what the indicator showed at that time. Adding it to a chart does not place a trade. Practise reading it before any simulated execution.

AICoin

Search terms：腾落线 / Advance Decline Line / ADL

Search hints only; US equity breadth support unverified. One crypto chart cannot supply stock counts.

  1. Open the AICoin web chart below. Select an exchange and pair, such as BTC/USDT. Check whether you selected spot or a perpetual contract: their data can differ.
  2. Look for the chart-top Indicators button, labelled 指标 in Chinese. Search the abbreviation below first, then try the other terms. Common indicators may also appear in the shortcut bar below the chart.
  3. Add only an exact matching result. Check whether it appears over price or in a separate pane. Similar names do not guarantee the same formula.
  4. If the implementation exposes parameters/settings, open them and start with the defaults, then follow the interpretation steps on this page. Check the official help if your interface differs.
  5. No result may mean the feature is unavailable in your version. Check existing Custom indicators (自定义指标) only if you can verify their formula. Otherwise learn it on a platform that supports it; do not assume every indicator here is built in.
