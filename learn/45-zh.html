Vortex 涡旋指标

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

Vortex 比较一根 K 线与前一根高低点之间的移动，画出 VI+ 和 VI-，帮助看上涨推动还是下跌推动更占优势。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像两股水流的拉力计，看哪股水流暂时更强。

举个例子（虚构数字，只为讲解）

示例：VI+ 从 VI- 下方穿到上方，只说明计算中的向上移动占优，仍要看价格能否跟上。

先知道：为什么要看这个指标？

比较相邻 K 线之间向上与向下的移动哪一种更突出。Vortex 用 VI+ 和 VI− 两条线描述方向力量的相对大小，帮助发现结构变化。

什么时候看它比较有意义

价格从横盘开始有方向，或原来趋势可能换边时，观察两条线是否有持续领先；它在小幅来回行情中容易频繁交换位置。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 Vortex 窗格
通过图例认 VI+ 与 VI−，纵轴是经真实波幅归一化的比值，没有美元单位；常在 1 附近，但不是限定 0 到 1 的概率。
两条线的相对位置和上方价格
先看哪条高，再看差距有没有连续扩大；沿时间轴回到主图核对真实高低点是否同向。

第二步：看到变化，怎么读懂？

你看到：VI+ 从下方穿到 VI− 上方并持续领先

这说明什么：最近向上方向的跨 K 线运动占优，值得继续观察上行结构。

还不能说明什么：不是任何一次交叉都必须买入。

你看到：VI− 在上，差距越来越大

这说明什么：向下方向运动相对更强。

还不能说明什么：数值大不等于下跌金额一定大。

你看到：两线靠拢且反复交叉

这说明什么：双方轮流领先，方向可能不稳定。

还不能说明什么：交叉次数多不表示交易机会更优质。

最容易看错的地方

窄幅来回走时会产生很多假转向提示。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构日线读数：VI+=0.85、VI−=1.12；之后变为 1.18 与 0.89，再连续两天保持这个次序。

  1. 最初 VI− 较高，计算窗口内下行运动领先。
  2. 次序反转并持续，向上运动开始占优。
  3. 若主图同时由低点 90 抬高到 93、96，这比单独一次交叉更能支持结构转强的解释。

把观察连起来，你可以这样说

观察结果是方向优势换边并获得价格高低点的呼应，不是凭颜色猜涨跌。

但不要跳到这个结论：仍可能是假突破；VI+=1.18 不代表上涨 18%，也不是 118% 胜率。

最后试一题：你真的看懂了吗？

VI+ 和 VI− 每天交叉，主图一直在 98 至 102 之间，先想到什么？

想好后，点开答案与解释

方向优势不稳定，可能是区间噪声。不能把每次交叉都当作一段新趋势。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Vortex Indicator

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 核对 VI+ 与 VI- 两条线；先用默认窗口，不将线的颜色当作固定含义。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：涡旋指标 / Vortex Indicator

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：核对 VI+ 与 VI- 两条线；先用默认窗口，不将线的颜色当作固定含义。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
