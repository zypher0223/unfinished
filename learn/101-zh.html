Volume Delta 成交量差值

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

它比较一根K线内偏买方与偏卖方的成交量差额。注意 TradingView 内置版本主要用更小周期价格变化估算方向。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像统计拔河中两边用了多少力气，但这把尺子有时是从脚步推算力气。

举个例子（虚构数字，只为讲解）

仅作示例：估计正向成交600、负向400，差值+200；不代表只有600人在买，因为每笔成交都有买方和卖方。

先知道：为什么要看这个指标？

成交量差额Volume Delta比较一根K线里被归为正向和负向的成交量。正数表示正向量减负向量后仍有剩余，负数反之。每笔成交都有买卖双方，不能把它理解成只有买没有卖。尤其要先问数据怎样分类：真实逐笔主动成交分类，与用更小周期涨跌推算分类，是不同信息，不能把估算说成亲眼看到了全部订单。

什么时候看它比较有意义

适合把交易活动与价格进展放在一起看：偏正的活动是否真的推动了上涨？这里的差额是成交数量，不是流进交易所的资金金额。先固定交易所、交易对、成交量单位和估算使用的更小周期，才有前后比较意义。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

副图零线和差额柱或蜡烛
零线分正负。TradingView常见内置版本从零起算每根，收盘位置是这一根最终估算差额，上下影表示内部过程中达到过的差额极值；不是资产价格高低。其他脚本可能仅用柱状显示。
对应的主图K线与数值刻度
上下对齐同一时间再读。单位可能是股、币或合约，由数据源决定；+200不是200人，也不是200美元。实时未结束K线的差额还在变化。

第二步：看到变化，怎么读懂？

你看到：价格上涨、差额偏正

这说明什么：这一根价格与所选分类中的正向活动大致同步。

还不能说明什么：不保证下一根继续涨。

你看到：差额很正但价格几乎不涨

这说明什么：正向活动未换来同等价格进展，值得继续观察阻碍。

还不能说明什么：不能直接证明机构吸收或马上暴跌。

你看到：差额为负但价格仍涨

这说明什么：价格与分类差额不一致，需查数据口径和后续表现。

还不能说明什么：不一定是软件错，更不能断定价格马上回落。

最容易看错的地方

正差值也可能配合下跌；交易所之间与估算方法之间不可直接混用。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构例子：同一根五分钟K线的小周期分类量，正向600份、负向400份。

  1. 差额为600−400＝+200份，总成交量却是1000份；两者不是同一数字。
  2. 主图从100收在101，先得到这根价格上涨且差额为正。
  3. 下一根差额+500，价格却收100.8，较强的正差额没有使收盘更高，说明活动与价格进展不同步。

把观察连起来，你可以这样说

差额增加提供观察线索，价格有没有真正向上移动要另外读，不能只看正柱大就追。

但不要跳到这个结论：估算不能确认谁在买卖，也不揭示全市场净资金流入或下一根方向。

最后试一题：你真的看懂了吗？

正差额200、总成交1000，能说只有600份买单且没人卖吗？

想好后，点开答案与解释

不能。每份成交都有买卖双方。例子的600和400只是按某种规则划成的两类，差额200是两类相减；若来自小周期估算，更不能当成精确的主动逐笔买卖记录。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

订单流统计概念；单一创始人未确认 / Order-flow measure

买卖成交差值是通用统计；TradingView具体内置算法由其平台实现，未证实概念的首位提出者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Volume Delta

官方内置；看下级周期设置并理解估算限制。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：成交量差值 / Delta / 主动买卖差

仅为查找词；未确认同款可用性，需查数据源及买卖分类方法。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
