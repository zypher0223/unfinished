SMMA/RMA 平滑均线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

这是一条转弯较慢的平均线。常见RMA算法每次只把新价格的1/N放进来，其余保留旧平均值，所以比较平稳。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像一大锅汤里每次只加一小勺新水，味道不会突然大变。

举个例子（虚构数字，只为讲解）

计算示例：14期RMA原来100，新收盘114，新值是100+(114−100)÷14=101。

先知道：为什么要看这个指标？

SMMA/RMA让新价格一点点进入旧平均，常见RMA每根只给新价1/N的分量。它的目的，是让背景方向少受一根尖刺影响；代价是突然转向时跟得慢。先确认看的确实是价格平滑线，因为RSI里的RMA可能是在平滑RSI数值。

什么时候看它比较有意义

价格噪声很多、你想先辨认较平稳的平均方向时有帮助。它适合描述背景，不适合把每次短线变化都立即判为新趋势；看慢线仍上行时，尤其要记得价格可能已经先跌了一段。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图中标SMMA或RMA的价格曲线
使用收盘价时，右轴单位与价格相同。14期表示平滑权重用1/14，不是只保留14天然后全部重算的简单平均。不同软件起始计算可能有差异。
曲线转弯前后的实际K线
先看价格发生什么，再看线隔几根才改变方向；这段间隔就是平滑带来的迟到。不要把慢理解为提前知道。

第二步：看到变化，怎么读懂？

你看到：价格急涨，RMA只略微抬高

这说明什么：新价格只占小部分，旧平均仍占大部分。

还不能说明什么：不是涨幅很小，也不是指标坏了。

你看到：价格已经回落，RMA仍上行

这说明什么：当前价可能仍高于旧平均，线还在被向上拉。

还不能说明什么：不证明价格没有转弱。

你看到：RMA走平，价格多次横穿

这说明什么：平滑后的背景方向不明显。

还不能说明什么：不是未来价格会一直不动。

最容易看错的地方

名字相似不代表软件初始值和算法完全一致；平滑也意味着变化发现得更晚。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构14期RMA，昨天为100元。每次新值=旧值+(新收盘−旧值)÷14。

  1. 今天收114，RMA只升到101，而不是114。
  2. 明天收108，RMA约101.5；价格由114跌到108，线却仍上升。
  3. 后天收94，RMA约100.96，才开始下行，价格已远在线下。

把观察连起来，你可以这样说

线方向反映新价和旧平均之间的关系。它过滤了急涨的冲击，同时也迟一些显示转弱；必须把价格和平均线分别读。

但不要跳到这个结论：平滑线没有给出可靠底部；线与价格的距离也不是一定会很快收回的欠账。

最后试一题：你真的看懂了吗？

RMA还在升，能忽略连续两根明显下跌的K线吗？

想好后，点开答案与解释

不能。慢线保留大量旧数据，本来就可能继续升。先承认价格已经回落，再观察是否持续收在线下，不能用滞后平均否认眼前的价格。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

RMA常与J. Welles Wilder相关 / RMA associated with J. Welles Wilder

Wilder在其指标体系中采用这种平滑方式；通用SMMA名称并不足以证明由他首次发明或首次使用。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Smoothed Moving Average

官方内置；其他指标设置中的SMMA(RMA)是对该指标数值再平滑，未必是价格均线。 操作练习：搜索Smoothed Moving Average，演示设14期和收盘价。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：SMMA / RMA / 平滑均线

独立入口和算法未核验；搜不到时保留为不可用。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
