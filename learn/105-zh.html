New Highs/New Lows 新高新低广度

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

数一个市场里，有多少股票创选定期间的新高，有多少创新低。它看强弱是扩散还是缩小。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

数一支队伍里有多少人刷新最好成绩，又有多少人跌到最差。

举个例子（虚构数字，只为讲解）

仅作示例：同样是指数上涨，100家公司创一年新高，比只有5家创新高的参与面更广。

先知道：为什么要看这个指标？

新高新低家数统计一群股票里，有多少创指定时期的新高、有多少创新低。它想知道强势或弱势有没有扩散，像数全班有多少人刷新个人最好成绩。这里的新高要先说明期间，例如52周最高；它不是今天比昨天涨就算新高，更不是某一只股票画出一条新高线。

什么时候看它比较有意义

你想知道指数上涨是否带动更多成员进入强势区时使用。先固定股票集合、回看周期、采用盘中高低还是收盘，以及数据频率；500家和3000家的原始数量不能公平直比，必要时换成占总数比例。用于加密市场也必须明确币种集合，单一交易对不等于市场广度。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

广度面板中的新高线、新低线或柱
通过图例确认哪条是哪条，读右侧数量单位是家。某些版本只画新高减新低，正值说明新高家数较多，不代表每一只股票都上涨。
集合名称、期间与同市场指数
先查是52周还是20天，是交易所全体还是指数成员。和同一集合的指数对照变化，不能把一条市场家数线与不相关资产价格硬配。

第二步：看到变化，怎么读懂？

你看到：新高家数连续扩张且新低很少

这说明什么：更多成员达到所选期间高位，强势参与在扩散。

还不能说明什么：不等于上涨不会结束，也不代表此刻新买都合适。

你看到：指数新高但新高家数越来越少

这说明什么：指数的纪录没有被同样多的成员分享，参与可能集中。

还不能说明什么：不证明明天就见顶。

你看到：新低家数突然增加

这说明什么：更多成员跌到指定期间低位，弱势范围扩大。

还不能说明什么：不能因为很差就自动判断跌到底或值得抄底。

最容易看错的地方

一天可以因极端波动同时触及不同阈值；高低周期不同，结论也不同。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构500家公司集合，统一统计52周新高新低，未改变成分。

  1. 第一天100家新高、10家新低，分别占20%和2%，差额+90。
  2. 几天后指数再创高，但只有20家新高、40家新低，分别4%和8%，差额−20。
  3. 指数创新高是价格指数事实，成员新高范围缩小也是事实；这两件事可同时发生，常见原因之一是大权重表现不同。

把观察连起来，你可以这样说

新高新低家数为指数补上一张参与情况表，提示进一步检查内部强弱。

但不要跳到这个结论：不能仅凭家数判断谁在操纵或何时反转，时期和统计规则改变也会改变结果。

最后试一题：你真的看懂了吗？

某市场100家新高，另一市场200家新高，后者一定更强吗？

想好后，点开答案与解释

不能只比数量。若前者共500家，比例20%；后者共3000家，比例约6.7%。还要统一新高的观察期间和统计方法，才能讨论哪边参与范围更广。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

通用市场广度统计；单一创始人未确认 / Generic breadth statistic

统计新高新低家数是长期市场实践；某些衍生指标有作者，但不能推定所有新高新低统计都由其首创。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：New highs / New lows / Market breadth

官方市场广度字段与数据代码可用性按市场而异；不是每个资产都能添加的单图指标。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：新高新低 / 市场广度 / New Highs New Lows

仅为查找词；股票广度覆盖未确认，不把单币新高误当市场家数。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
