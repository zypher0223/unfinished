Pivot Points 标准枢轴点

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

把上一段时间的最高、最低和收盘价算成今天的一组水平参考线。P是中间参考，R通常表示上方阻力，S表示下方支撑。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

用昨天的活动范围，给今天先画一张路标图。

举个例子（虚构数字，只为讲解）

仅作示例：昨日高110、低90、收100，传统P=(110+90+100)/3=100，R1=110、S1=90。

先知道：为什么要看这个指标？

枢轴标准点用上一段已经完成的高、低、收盘价，为下一段画一组水平路标。P是中心参考，R1、R2等是按公式算出的上方参考，S1、S2是下方参考。支撑阻力这些称呼只是常用名称，意思是到附近观察价格怎样反应，不是价格必须停下的墙。它与事后识别局部高低点的Pivot High/Low不是同一件事。

什么时候看它比较有意义

适合在当天开始前标好观察位置，减少盘中随意画线。先选Traditional等明确公式，确认上一段是日、周还是月，以及是否使用常规交易时段和结算数据。公式或时段改变，路标也会改变，不是哪个画得更多就更准确。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图标有P、R、S的水平线
先读字母和右侧价格，例如P＝100美元。横线单位与价格相同，不是分数或胜率；同一组通常只在对应枢轴周期内适用。
当前已结束K线与线附近的价格行为
观察价格是第一次靠近、快速穿过、停留，还是穿过后回到原侧。先读真实收盘，再描述反应；并非只要影线碰到就完成有效测试。

第二步：看到变化，怎么读懂？

你看到：价格在P上方交易

这说明什么：现价相对这组中心参考较高，可作当天位置背景。

还不能说明什么：不是今天必涨，也不表示回落到P必须买。

你看到：到R1附近多次停顿并回落

这说明什么：目前价格确实在这个历史公式位置附近遇到阻碍。

还不能说明什么：不证明公式造成阻碍，更不保证下一次仍有效。

你看到：收盘越过R1后在上方持续交易

这说明什么：价格暂时接受了比R1更高的位置，应重新观察。

还不能说明什么：不应因名字叫阻力就断言必须马上跌回。

最容易看错的地方

不同交易时段与结算数据会算出不同数值；线多不意味着预测准确。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构例子采用传统公式：昨日最高110、最低90、收盘100。

  1. P＝（110＋90＋100）÷3＝100；R1＝2×100−90＝110；S1＝2×100−110＝90。
  2. 今天从102走到110，两根K线都收109，得到的是靠近R1后暂未站上。
  3. 随后一根收111、下一根收112，先前停顿已被穿越，应更新观察，不能坚持阻力永不失效。

把观察连起来，你可以这样说

公式提前提供位置，后续价格反应提供证据；二者要分开记录。

但不要跳到这个结论：这些价格不预测今天的最高最低，也不代表碰线就存在可获利交易。

最后试一题：你真的看懂了吗？

别人的R1与你相差两元，是否说明其中一人算错？

想好后，点开答案与解释

未必。先核对公式类型、日周周期、时区以及盘前盘后和结算口径。输入的上一周期高低收不同，算出的线本来就不同；先统一问题再比较答案。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

传统场内交易方法；单一创始人未确认 / Traditional floor-trading method

标准枢轴点来自传统交易实践；未找到可靠证据确认所有版本共同的第一个提出者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Pivot Points Standard

官方内置；查看 Type、Pivots Timeframe 和日线数据设置。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：枢轴点 / Pivot Points / PIVOT

仅为查找词；未确认当前同款支持，须核对公式与时间口径。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
