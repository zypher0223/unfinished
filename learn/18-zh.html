PPO 价格百分比振荡器

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

PPO和MACD很像，但把快慢均线的差换成百分比。这样100元与10000元资产的读数更容易放在同一种尺度上看。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

比较两家店涨价幅度时看百分比，而不只看各自涨了几元。

举个例子（虚构数字，只为讲解）

计算示例：快均线102，慢均线100，PPO=(102−100)÷100×100=2%。

先知道：为什么要看这个指标？

PPO把快慢EMA的差除以慢EMA，变成百分比。它和MACD类似，但不再用几元的差，而用相对差多少百分比，更便于在不同价位观察。信号线平均PPO，柱子显示PPO领先或落后信号线多少。

什么时候看它比较有意义

想看短期平均相对长期平均增强还是转弱，而且避免高价资产天然差值很大时，可用PPO。它便于比较刻度，却不能消除资产风险、交易时段和波动特性差异。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方PPO窗的主线、信号线与零线
看图例认线。PPO=2表示快EMA高于慢EMA约2%，不是持仓盈利2%；零线表示两均线相等。12、26、9分别是快、慢、信号长度。
零线上下的柱子与相邻柱长
柱为PPO−信号线，通常用百分点理解。例如2%减1.5%=0.5个百分点。颜色仅辅助，先按正负与伸长缩短判断。

第二步：看到变化，怎么读懂？

你看到：PPO为正并上升

这说明什么：快均价相对慢均价的优势扩大。

还不能说明什么：不等于每根价格都在涨，更不是账户回报。

你看到：PPO仍为正但柱缩短

这说明什么：主线对较慢信号线的优势收窄，近期推动可能放缓。

还不能说明什么：不一定快均价已经低于慢均价。

你看到：PPO为负、负柱逐步缩小

这说明什么：快均价仍偏低，但相对信号线的弱势减轻。

还不能说明什么：不等于上涨趋势已经建立。

最容易看错的地方

PPO是均线差百分比，不是账户收益率；不同资产读数可比较也不代表风险相同。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构快EMA102元、慢EMA100元，PPO=(102−100)÷100×100=2%；9期EMA信号线1.5%，每根给新PPO20%权重。

  1. PPO2%说明快均价高2%，标准柱为0.5个百分点。
  2. 下一根PPO2.05%，信号线=1.5%×0.8+2.05%×0.2=1.61%，柱缩至0.44个百分点，主线本身却仍增加。
  3. 再下一根PPO1.5%、信号约1.588%，柱约−0.088个百分点；主线仍正，说明快均价尚高于慢均价。

把观察连起来，你可以这样说

读零线判断均价相对高低，读柱判断主线相对自身平均的变化。两个层次不能混为一个买卖标签。

但不要跳到这个结论：PPO2%不保证接下来赚2%，也不能因两资产PPO相同就认为仓位风险相同。

最后试一题：你真的看懂了吗？

PPO在零线下却向上穿过信号线，代表什么？

想好后，点开答案与解释

快均价仍低于慢均价，但这份弱势相对近期平均在改善。它可以是反弹早期，也可能只是短暂改善；是否突破和延续要回主图观察。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

未确认唯一创始人 / No single inventor verified

PPO是两条均线差的百分比表达；本次未核实其独立创始人，不把MACD作者直接当作PPO首创者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Percentage Price Oscillator

官方内置PPO。 操作练习：添加Percentage Price Oscillator，先保留12、26、9。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：PPO / 价格百分比振荡器

内置入口未核验；不要用MACD原始数值代替百分比。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
