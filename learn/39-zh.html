Supertrend 超级趋势

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

Supertrend按近期波动大小，在价格一侧画跟踪线。收盘越过线后，它改变跟踪方向；线的距离由ATR和倍数决定。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

给价格配一条能随路面颠簸程度调整距离的跟踪警戒线。

举个例子（虚构数字，只为讲解）

计算示例：本根高低中点100、ATR2、倍数3，基础上下界为106与94；实际跟踪线还会沿用前一根规则，不只是这两个数。

先知道：为什么要看这个指标？

Supertrend用ATR和倍数在价格一侧画跟踪线，达到翻转条件后换到另一侧。它把平均波幅变成随走势移动的参考边界，帮助你观察算法认定的方向。‘超级’只是名称，不能理解为特别可靠或没有假信号。

什么时候看它比较有意义

想学习如何让跟踪距离随市场波动变宽变窄时很适合。ATR变大时距离可能更宽，倍数变小会更敏感；方向明显时较易读，横盘则可能频繁翻转。先理解这些取舍再讨论参数。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图价格上方或下方的分段线
线在下方常是向上跟踪，上方常是向下跟踪；按图例和位置认，不依赖红绿。右侧线值是价格，不是ATR倍数本身。
翻边对应的已收盘K线与ATR参数
标准Supertrend常以收盘越过最终跟踪线确认方向；当根未完成可能变化。实际线沿用前值与规则，不等于每根都直接画中点±ATR倍数。

第二步：看到变化，怎么读懂？

你看到：线在下方逐渐抬高，收盘维持其上

这说明什么：算法维持向上跟踪，参考边界随走势抬高。

还不能说明什么：不保证价格碰线会反弹。

你看到：收盘越过原线后线翻到上方

这说明什么：标准规则进入向下状态，可检查价格是否持续走弱。

还不能说明什么：翻边不是自动卖单，也不一定是长期转熊。

你看到：上下翻边很频繁

这说明什么：当前价格范围相对规则太容易来回触发，趋势不清。

还不能说明什么：更多信号不等于更多收益。

最容易看错的地方

名字叫超级不代表特别可靠；趋势走完才翻边会迟到，横盘则可能连续翻错。它不会自动下止损单。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构ATR10、倍数3，当前高低中点100、ATR2，基础上界106、下界94；假定最终跟踪下线依历史规则为95。

  1. 价格收103在线95上方，算法保持向上；不能把基础下界94误读为最终线95。
  2. 下一根收94低于原参考线，标准规则可能翻为上方跟踪，具体新上界仍取决于递推规则。
  3. 若几根后又收回上方并翻回，说明一次翻转可能失败，横盘中尤其常见。

把观察连起来，你可以这样说

先读实际最终线的位置与已收盘是否越过，再解释状态；公式基础带和最终跟踪带要分开。

但不要跳到这个结论：3倍ATR不是保证价格不会越过的安全距离，也不能确保任何翻边有利润。

最后试一题：你真的看懂了吗？

把倍数从3降到1，线更贴价，是否一定更安全？

想好后，点开答案与解释

不一定。距离变近会更早触发，也更容易被普通波动反复穿越。安全要看完整仓位与计划；更敏感只是一种计算取舍。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Supertrend

官方内置；社区有很多变体，先选Technicals中的标准版本。 操作练习：添加Supertrend，演示用ATR10期、倍数3。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：Supertrend / 超级趋势

可用性未核验；若有社区版本，先核对ATR周期、倍数、收盘翻转规则。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
