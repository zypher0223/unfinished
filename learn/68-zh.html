RCI 排名相关指数

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

RCI 把价格按高低排名，再和时间先后比较。一路按顺序越走越高，分数接近 +100；一路越走越低接近 -100。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像一列人按身高排队，越排越整齐，方向就越一致。

举个例子（虚构数字，只为讲解）

示例：最近收盘依次为 10、11、12、13，排名与时间一致，RCI 接近 +100。

先知道：为什么要看这个指标？

检查价格高低排名是否与时间先后排列一致。RCI 关注价格是不是有条理地越走越高或越走越低，而不只看起点终点。

什么时候看它比较有意义

想区分有秩序推进与来回折返，或比较同一窗口内价格顺序是否开始混乱时使用；排名不等于涨幅。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 RCI 曲线和零线
纵轴常为 −100 到 +100，无货币单位；+100 接近按时间顺序越来越高，−100 接近越来越低，0 表示顺序关系弱。
主图最近若干根收盘顺序
把较早和较晚价格按高低排名，观察是否大体顺排。每天只涨一分钱也可能高度有序，所以高读数不必伴随大涨幅。

第二步：看到变化，怎么读懂？

你看到：RCI 接近 +100

这说明什么：该窗口后来的价格普遍排在更高位置，顺序较整齐。

还不能说明什么：不表示已经上涨 100%。

你看到：RCI 接近 −100

这说明什么：价格按时间越来越低的次序很整齐。

还不能说明什么：不表示必将触底反弹。

你看到：RCI 从高正值回到零附近

这说明什么：原有向上顺序被来回变化打乱。

还不能说明什么：不一定已变成有序下跌。

最容易看错的地方

它比较先后顺序，不直接反映涨跌幅大小；微涨也能得到很高分。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构五个收盘 100、101、102、103、104，排列非常整齐；另一组为 100、104、99、103、101。

  1. 第一组随时间依次变高，排名关系接近最强正向。
  2. 第二组虽然最后比开头高 1，途中却频繁打乱顺序，因此 RCI 会低得多。
  3. 若第一组后面开始交替涨跌，RCI 会降温，但未必立刻变负。

把观察连起来，你可以这样说

RCI 描述趋势的顺序性，价格涨幅与顺序性必须分开读。

但不要跳到这个结论：有序上涨不证明还会持续，±80 也不是所有市场通用的反转按钮。

最后试一题：你真的看懂了吗？

每天从 10.00、10.01 到 10.02，有可能 RCI 很高吗？

想好后，点开答案与解释

有可能。它重视排名顺序而非涨幅大小，细小但持续的上升也可非常有序。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

统计方法；首位交易提出者未确认 / Statistical method; trading origin unverified

RCI 基于 Spearman 等级相关；官方未确认将这一版本首用于交易的个人。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Rank Correlation Index

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 内置名称 Rank Correlation Index；先保留默认长度，范围 -100 至 +100，±80 只是常见参考。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：排名相关指数 / Rank Correlation Index

未核实 AiCoin 是否提供 RCI。若找到排名相关脚本，先核对它比较的是价格排名与时间顺序；常见尺度 -100到+100，±80 只是教学参考。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
