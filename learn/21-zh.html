Bollinger Bands 布林带

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

中线是平均价格，上下两条线会随近期价格分散程度张开或缩小。它告诉你价格相对近期范围偏高还是偏低，也告诉你市场是否变得更爱折腾。

小数字算一遍，再理解三种状态

独立算例：下面的数字用于手算，不是上图数据。

假设中轨SMA=100、总体标准差σ=2、倍数k=2，则上轨104，下轨96；触上轨不等于“太贵必跌”。

  1. 贴上轨：相对本窗口偏强，趋势可沿轨延续。
  2. 贴下轨：相对本窗口偏弱，不自动构成买点。
  3. 轨道收窄：近期波动收缩，未告诉你下一步方向。
第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像会伸缩的道路护栏，平静时变窄，颠簸时变宽。

举个例子（虚构数字，只为讲解）

计算示例：中线100、标准差2、倍数2，上轨104，下轨96。标准差就是价格偏离平均值的分散程度。

先知道：为什么要看这个指标？

布林带画一条近期均价中线，再按价格分散程度画上下轨。分散程度越大，轨道通常越宽。它同时帮你看‘相对近期范围的位置’和‘波动有没有变化’，上轨下轨不是保证挡住价格的墙。

什么时候看它比较有意义

既想分辨安静期与活跃期，又想看价格是贴着一侧走还是围绕中线摆动时很有用。同样碰上轨，在强趋势可能表示持续强，在横盘可能只是到区间上端；要先认上下文。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图三条线：中轨、上轨、下轨
常见20期SMA加减2倍标准差，三条都用右侧价格单位。标准差是近期价格分散程度，不是成交量。按名称认轨道，不以颜色为准。
两轨间宽度及每根收盘所处位置
看轨道在张开还是收窄，再看收盘靠近哪侧；盘中上影碰轨与连续收在轨外是不同画面。当前未收盘的轨道也可能变化。

第二步：看到变化，怎么读懂？

你看到：带子收窄，价格活动范围也小

这说明什么：近期价格分散减小，市场暂时较安静。

还不能说明什么：不告诉你下一步涨或跌，安静也可持续。

你看到：价格连续靠上轨，带子张开且中线升

这说明什么：方向偏强，同时近期波动扩大。

还不能说明什么：碰上轨不能单独解释为必须卖。

你看到：一根冲出下轨后又收回带内

这说明什么：发生向下偏离后收回，应观察后续能否维持。

还不能说明什么：不保证底部形成，下一根仍可继续下跌。

最容易看错的地方

上轨不是天花板，下轨不是地板；价格可以贴着轨道继续走，也可以跑到轨道外。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构20期均价100元，价格标准差2，倍数2，上轨104、下轨96。

  1. 收103在中轨上、上轨下，表示相对本窗口偏高。
  2. 后来均价升至102、标准差3，上下轨108和96；收107虽然更高，仍在带内。
  3. 若下一根收109高于108，只说明超过当前统计轨道；轨道之后也会被新价格重新计算。

把观察连起来，你可以这样说

要同时读位置、带宽、中线方向，而不是盯一次碰线。范围会随新数据改变，不能把历史轨道当未来边界。

但不要跳到这个结论：两倍标准差没有保证固定概率或保证价格回中线；市场并不总符合简单正态分布假设。

最后试一题：你真的看懂了吗？

价格碰上轨后又上涨三根，是不是布林带失效？

想好后，点开答案与解释

不一定。上轨是相对分散程度算出的参考，不是天花板。贴上轨延续本来就是可能出现的强趋势画面，要看收盘与带宽变化。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

John Bollinger

Bollinger于1980年代初开发布林带，其本人官网有介绍；未据此指定其第一笔实盘交易。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Bollinger Bands

官方内置BB；不要选同名策略来替代指标。 操作练习：添加Bollinger Bands，先用20期、2倍标准差。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：BOLL / BB / 布林带

官方文档列有布林带。先用20期、2倍标准差，辨认中上下面三条线；不要把倍数理解为百分比。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
