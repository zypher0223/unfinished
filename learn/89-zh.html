Chandelier Exit 吊灯止损

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

它从近期最高点向下留出一段缓冲距离，给已经买入的人一个退出参考；做空则反过来。缓冲通常按 ATR，也就是最近每根K线大概波动多少来算。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

像挂在天花板下的吊灯：天花板升高，灯也跟着升，但中间留出摆动空间。

举个例子（虚构数字，只为讲解）

仅作示例：近期最高110，ATR为2，倍数3，多头退出参考为110−2×3＝104。

先知道：为什么要看这个指标？

吊灯止损帮助已经持仓的人思考：如果价格从近期高点退回多少，我要重新检查继续持有的理由？多头参考通常从近期最高价减去若干倍平均真实波幅。平均真实波幅简称ATR，可以先理解为近期每根K线通常晃动多少价格单位。它用正常晃动留缓冲，不负责告诉你这项资产该值多少钱。

什么时候看它比较有意义

适合先研究退出计划。买入后盼涨的叫多头，先卖出盼跌的叫空头；两种持仓看的参考线不同。先在模拟记录中确定采用收盘跌破还是盘中触及作为检查条件，别看见价格快碰线才临时改规则。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图价格旁的Long Exit和Short Exit图例
按文字确认多头退出线与空头退出线，不按红绿猜。线和价格共用右侧价格刻度，单位是美元、元或该交易对报价单位，不是概率。
近期高低点、ATR长度与倍数
多头线通常从最高位置向下留ATR乘倍数的距离；空头线反向处理。长度是一段多少根K线，倍数决定留多宽，不是允许账户亏多少倍。

第二步：看到变化，怎么读懂？

你看到：价格在多头退出线上方并拉出新高

这说明什么：按这套退出参考，多头持有条件尚未被触及。

还不能说明什么：不代表此刻适合新买入，更不保证会再创新高。

你看到：收盘跌到多头线下

这说明什么：你预先采用的收盘检查条件被触发，应执行既定复核流程。

还不能说明什么：图线不会替你提交或成交止损单。

你看到：波动突然增大，线与高点间隔变宽

这说明什么：公式给正常晃动留出的距离增加。

还不能说明什么：不表示应扩大已经承诺的最大损失；原公式也不必始终单向收紧。

最容易看错的地方

图上的线不是自动成交的止损单；原始公式的线也不一定每一根都只向有利方向移动。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构例子：买入持仓，近期最高110元，ATR为2元，倍数3。

  1. 多头参考为110−2×3＝104元，所以价格108尚在线上。
  2. 后来最高升到114、ATR仍为2，参考升到108；这来自新高抬高，不是软件知道未来。
  3. 接着收盘107，跌穿108，符合事先写好的收盘退出检查条件。

把观察连起来，你可以这样说

把宽泛的害怕下跌变成可读的价格边界；是否委托以及怎样委托仍要按独立计划执行。

但不要跳到这个结论：不能保证在108成交，跳空、滑点和公式变化都可能造成差别。

最后试一题：你真的看懂了吗？

吊灯线显示104，我账户就最多亏到104吗？

想好后，点开答案与解释

不是。104只是图上根据历史数据算出的参考价。没有真实保护委托就不会自动卖出；即使有委托，市场跳过价格时成交也可能偏离。先区分指标信息与交易执行。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Chandelier Exit

官方内置指标；不要混淆同名社区版本。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：Chandelier Exit / 吊灯止损 / CE

仅为查找词；未确认内置同款，指标显示也不代表自动止损。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
