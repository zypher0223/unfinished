Ulcer Index 溃疡指数

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

它专门看从近期高位跌下来有多深、低迷了多久。数字越大，最近持有过程中的下跌压力通常越大。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

不是统计路有多颠，而是统计掉进坑里有多深、多久没爬出来。

举个例子（虚构数字，只为讲解）

仅作示例：两只资产最后都回到100元，一只只短暂跌到99，另一只在80附近待了很久，后者通常更难熬。

先知道：为什么要看这个指标？

Ulcer Index中文常叫溃疡指数，专门衡量价格跌离近期高点的压力。普通波动把向上大涨和向下大跌都算作晃动；它更关心持有者掉进坑里多深、多久没恢复。因此它适合比较过去的持有过程是否难熬，而不是寻找一个碰到就买的价位。

什么时候看它比较有意义

当你想比较同类资产的历史下跌压力，或检查一段上涨是否伴随深而持久的回撤时使用。回撤就是从已经到过的高点往下跌。比较时要用相同K线周期、计算长度和时间区间；一个用五分钟、另一个用日线，数字没有公平比较基础。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图近期最高位置与后续收盘
先看价格离已经出现的高点有多远、低位待了几根；这是副图升降的实际来源。回看窗口里的高点会随时间滚动，不是永久历史最高。
副图曲线与右侧刻度
曲线不会因涨跌方向而出现正负两边；0附近代表所选窗口内下跌压力很小，较大值代表较大压力。数值来自百分比回撤的统计，不能读成今天跌了几元或未来会跌几成。

第二步：看到变化，怎么读懂？

你看到：曲线从低位连续抬高

这说明什么：最近离高点的下跌更深或持续更久。

还不能说明什么：不代表下一根一定继续跌，也不提供下跌结束日期。

你看到：价格恢复、曲线逐步降低

这说明什么：新进入窗口的回撤较小，历史下跌压力在缓解。

还不能说明什么：不保证恢复能持续。

你看到：价格没涨多少，曲线却降低

这说明什么：旧的大回撤可能逐渐离开计算窗口，需要回头查原始价格。

还不能说明什么：不能只凭降低就称反转成功。

最容易看错的地方

它衡量过去的回撤，不会告诉你下一次下跌何时开始。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构简化观察窗只有三根收盘，用这三根中的高点100作对照。

  1. 三次收盘100、90、90，对应离100的回撤为0%、−10%、−10%。
  2. 把回撤平方后平均再开平方，约为8.16，反映这段下跌压力；它不是此刻价格跌幅10%的同义词。
  3. 若另一段是100、99、100，同样计算约为0.58，坑浅且很快回来，持有过程更平缓。

把观察连起来，你可以这样说

第一段历史下跌压力更大；实际软件会按自己的滚动窗口逐根计算，应先看说明和长度。

但不要跳到这个结论：较低的历史压力不证明资产便宜、未来安全或不会突然跳跌。

最后试一题：你真的看懂了吗？

两只资产今天都收100元，能说下跌风险体验一样吗？

想好后，点开答案与解释

不能。一只可能从99缓慢回到100，另一只刚从70爬回来。结束价相同不代表路程相同；要在相同窗口查看此前回撤的深度和持续程度，才知道这个指标想衡量什么。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Ulcer Index

官方内置指标；Length 是观察多少根K线。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：Ulcer Index / 溃疡指数

仅为查找词；当前内置可用性未确认。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
