我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

上轨记录最近N根的最高价，下轨记录最低价，中线在两者中间。它把最近价格活动的盒子画出来。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

给最近几天所有脚印套一个最大最小的框。

举个例子（虚构数字，只为讲解）

计算示例：最近20根最高110、最低90，通道就是110与90，中线100。

先知道：为什么要看这个指标？

唐奇安通道把最近N根最高价和最低价画为上下边，中线取两者中点。它让你清楚看到最近价格活动的范围，有没有逐渐抬高或降低。范围来自已经出现的最高最低，不是统计概率，也不预测下一根会停在哪。

什么时候看它比较有意义

想研究突破过去一段高点、跌破过去低点，或看价格长期困在哪个盒子里时有用。重点是分清‘当前这根包含在通道里’和‘拿当前价格与之前已定范围比较’，否则碰上轨常被误称突破。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图的上轨、下轨和中线
20期上轨是所包含20根的最高，下轨是最低，右轴用价格单位。边线常呈台阶，因为旧极值未移出前可能不变；中线并非20期平均收盘价。
上一根已完成通道与当前K线最高、收盘
先读上一根通道上界，再比较当前是否真的超过它。若通道包含当前根，当前创高会同步推高上轨；最高碰轨不等于收盘突破。

第二步：看到变化，怎么读懂？

你看到：上下轨都逐步抬高

这说明什么：近期最高和最低的活动范围在上移。

还不能说明什么：不保证之后一直上涨。

你看到：上轨不动，下轨持续降低

这说明什么：低端在走弱，范围扩大或向下扩展。

还不能说明什么：宽度变大不是向上行情。

你看到：两边长时间水平，价格在中间反复

这说明什么：近期尚未越过旧极值，区间较稳定。

还不能说明什么：不能知道下一次先突破哪边。

最容易看错的地方

碰到当前上轨并不等于突破过去20根最高点；要分清是否包含当前K线，以及是否等待收盘。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构上一根结束时20期最高110、最低90，中线100元。下一根最高112、最低105、收盘108。

  1. 盘中最高112超过此前110，出现向上越过旧范围的动作。
  2. 收盘108回到旧上界110之下，不能说收盘守住了突破。
  3. 若当前根计入通道，最新上轨已变112；看到最高碰112只是定义结果，不是第二次独立证据。

把观察连起来，你可以这样说

分别记录盘中越界和收盘回到范围内，理解突破是否保持。通道不会替你决定后续能否重新站上。

但不要跳到这个结论：没有证明回落一定延续，也不能把90当作今后绝不会跌穿的地板。

最后试一题：你真的看懂了吗？

当前最高刚好等于当前唐奇安上轨，能认定打破过去20根最高吗？

想好后，点开答案与解释

不能。当前根可能已经被算进去，而上轨本来就是包含范围的最高。要对比之前已完成的通道数值，并说明看的是最高还是收盘。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Donchian Channels

官方内置DC；Offset会移动显示，初学保持0。 操作练习：添加Donchian Channels，演示用20期。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：DC / Donchian / 唐奇安通道

官方文档列有唐奇安通道。演示用20期；确认是否包含当前K线以及偏移设置。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
