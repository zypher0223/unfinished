Advance/Decline 腾落线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

每天上涨家数减去下跌家数，再把每天的差额加起来。它看市场是不是很多股票一起走强，而不是只靠几个大公司撑指数。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

看全班有多少人进步，而不是只看第一名的成绩。

举个例子（虚构数字，只为讲解）

仅作示例：今天300只上涨、200只下跌，腾落线在昨天数值上加100。

先知道：为什么要看这个指标？

腾落线看的是一群股票有没有广泛参与涨跌，不是单只股票的K线。它每天数上涨家数减去下跌家数，再把每天差额累加。像看全班多少人进步，而不只看第一名成绩；大公司可以把指数拉高，但许多普通股票未必跟上。这里的家数是股票数量，不是涨了几元或交易了多少量。

什么时候看它比较有意义

你想检查一个市场指数上涨是不是少数大权重撑起来时使用。必须先指定股票集合，例如某交易所或某指数成分股，并配对同一市场的价格指数。把美股广度硬套到一个加密币上，不能得到这个币内部的参与面；加密若做广度，也要另定币种集合和数据。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

独立市场广度曲线、数据名称和集合说明
先核对这确实是上涨家数减下跌家数的市场数据，不是某些同名脚本按单个品种上涨K线减下跌K线。后者回答的是另一问题，不能替代本课的市场腾落线。
累计线方向与同市场指数
累计起点通常任意，绝对数值受起点影响，重点看同段升降和前高。纵轴是累计家数差，不是指数点位，不能拿两条线的高度直接比较。

第二步：看到变化，怎么读懂？

你看到：指数与腾落线一起创新高

这说明什么：指数上涨同时，多数股票参与的累计情况也较强。

还不能说明什么：不保证所有股票都涨或接下来继续上涨。

你看到：指数新高、腾落线低于旧高

这说明什么：上涨参与范围可能变窄，应查是否由少数大公司带动。

还不能说明什么：不表示指数一定马上跌。

你看到：腾落线持续下降

这说明什么：这段累计下来，下跌家数占优的日子和差额更占分量。

还不能说明什么：不等于每只股票天天下跌。

最容易看错的地方

它不是单个股票的涨跌K线计数；不同市场成分和退市处理会影响历史。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构500只股票集合，50只没变或未计入涨跌，累计线昨天为1000。

  1. 今天300只涨、150只跌，差额+150，累计升至1150；不能把300除以指数涨幅。
  2. 明天200只涨、250只跌，差额−50，累计降到1100。
  3. 若第二天指数仍从100涨101，说明指数价格上升但当天更多股票下跌，检查大权重贡献比宣称全面走强更准确。

把观察连起来，你可以这样说

把指数的结果与成员参与程度分开，才能辨认上涨是否广泛。

但不要跳到这个结论：两天样本不足以预测拐点；成分调整、退市及缺失数据会影响长期比较。

最后试一题：你真的看懂了吗？

给一只股票加上同名ADL脚本，就知道整个美股涨跌家数了吗？

想好后，点开答案与解释

不一定。先查它输入是否为市场上涨下跌家数，若只是统计这只股票的上涨下跌K线，它根本没有读取其他股票。市场广度必须有一群股票的数据，不会从一条价格线自动生出来。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

1930年代市场广度实践；Richard Russell（推广）

TradingView 记载1930年代已有应用，1960年代因 Richard Russell 的 Dow Theory Letters 更受关注。另有二手资料称 Cleveland Trust 的 Leonard P. Ayres 早在1926年就开始计算和分析涨跌家数，《巴伦周刊》1931年起刊登这类数据；目前仍不宜断言唯一发明者。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Advance Decline Line

有官方内置说明；确认输入广度数据所属市场，别误选 Advance/Decline Ratio (Bars)。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：腾落线 / Advance Decline Line / ADL

仅为查找词；美股广度数据支持未确认，加密单币K线无法直接提供股票家数。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
