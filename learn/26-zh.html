Moving Average Envelopes 均线包络线

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

先画平均线，再把它向上和向下各挪固定百分比，形成三条线。与布林带不同，宽度比例不会自动随波动改变。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

以一条路为中心，左右永远各留同样比例的距离。

举个例子（虚构数字，只为讲解）

计算示例：均线100，包络比例3%，上轨103，下轨97。

先知道：为什么要看这个指标？

均线包络先画平均线，再向上和向下各偏移固定百分比。它帮助你直接量‘价格比近期平均高或低多少比例’。宽度比例固定，不会像布林或ATR通道那样自动随近期波动强弱调整。

什么时候看它比较有意义

想用同一个明确百分比观察价格偏离平均，或研究不同波动环境里固定范围是否合适时有用。它尤其能让新手看到：某个市场的正常波动就可能经常超过3%，所以参数不是普适天花板。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主价格图的中线及固定比例上下轨
如中线20期SMA100、偏移3%，上轨103、下轨97。右轴是价格单位，3%是设置的相对距离，不是每天预计涨跌。确认中线采用SMA还是EMA。
收盘与轨道，以及过去平静和剧烈两段走势
观察同样3%在不同环境被碰到多少次；中线变化也会带动整条包络移动，不要把它当固定画好的水平线。

第二步：看到变化，怎么读懂？

你看到：价格多在线上半、三条线持续上移

这说明什么：价格相对平均偏强，平均背景也在抬高。

还不能说明什么：不保证碰上轨后会回落。

你看到：价格频繁穿透上下轨

这说明什么：固定百分比对当前波动可能太窄，不能有效区分异常。

还不能说明什么：不是连续出现大量必赚反转。

你看到：价格回中线，三条线仍上行

这说明什么：相对均值的偏离收敛，背景均价尚未转弱。

还不能说明什么：不能仅因回中线就确定上涨结束。

最容易看错的地方

3%只是示例，不适合所有股票和币；固定带宽不能自动适应市场变化。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构中线100元、3%包络，上103下97；第一天收102，第二天收105。

  1. 102在包络内，较中线高2%。
  2. 105超过上轨，较100高5%，只说明偏离超出设置的3%。
  3. 后来中线升到104，上轨变107.12、下轨100.88；价格仍105，如今又在带内，哪怕它没有下跌。

把观察连起来，你可以这样说

轨道跟着平均线移动，回到带内不一定是价格回落。必须同时记录中线和价格，才能解释相对偏离变化。

但不要跳到这个结论：3%不是统计保证，105超过上轨也没有证明价格被高估或必须回100。

最后试一题：你真的看懂了吗？

一只股票每天常波动1%，一个币常波动8%，都用3%包络，碰轨含义一样吗？

想好后，点开答案与解释

不一样。相对各自常态，3%的突出程度不同。固定比例没有自动适应这种差异，要先观察历史和波动，不能通用一套碰线买卖法。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

未确认唯一创始人 / No single inventor verified

固定百分比通道是长期演变的通用方法；John Bollinger本人回顾也明确表示百分比带的创造者不明。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Envelope

官方内置ENV，设置中选择是否用指数均线。 操作练习：添加Envelope，演示设20期、3%，确认用SMA还是EMA。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：ENV / Envelope / 均线包络

独立入口未核验；布林带不是固定百分比包络的同义词。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
