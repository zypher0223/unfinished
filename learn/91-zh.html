ATR Trailing Stop 跟踪止损

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

把最近价格通常能晃动的幅度乘几倍，留在价格后面当退出参考。上涨持仓常让保护线跟着新高抬升。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

遛狗时牵一根会随路况变长变短的绳子，而不是死守一米距离。

举个例子（虚构数字，只为讲解）

仅作示例：参考价100、ATR为2、倍数3，初始参考为94；价格升到105时，某些版本会把线抬到99。

先知道：为什么要看这个指标？

ATR跟踪止损用近期常见的价格晃动给持仓留空间，并在价格有利发展时移动退出参考。ATR指平均真实波幅，可先理解为每根K线大约动多少价格单位。它回答保护线离价格留多远更符合近期路况，不能回答价格将涨到哪里。跟踪表示参考会跟着移动，但不同脚本的移动规则并不相同。

什么时候看它比较有意义

你想为已经建立的持仓设计退出纪律时使用。先核对脚本是用收盘还是最高低价作参考、是否只向有利方向收紧、何时翻转。不要因为两个脚本都叫ATR止损，就把它们的线位和历史表现当作可互换。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图的跟踪线与价格刻度
买入持仓通常看价格下方的保护参考，做空通常看上方参考。刻度是资产价格，例如94美元，不是亏损6%这一数值本身。线变到另一侧可能是规则翻转，须读脚本说明。
ATR长度、倍数及最新已结束K线
长度决定用多少根估计日常晃动，倍数决定留几份空间。先读取已结束K线的线位，实时未结束的线可能随着高低价变化。

第二步：看到变化，怎么读懂？

你看到：上涨时保护线逐步抬高

这说明什么：该版本正在把退出参考向更高价格收紧。

还不能说明什么：不保证线能守住，也不表示每次抬高都需要加仓。

你看到：价格回落但尚在线上

这说明什么：按这套参考仍在允许的波动空间内。

还不能说明什么：不表示回落一定结束，或允许忽视账户最大亏损计划。

你看到：收盘穿线或线翻到价格上方

这说明什么：该脚本定义的退出或状态切换条件可能出现。

还不能说明什么：不表示价格必反向；横盘中可能连续翻转。

最容易看错的地方

同名脚本可能算法不同；ATR变大不意味着应随意放宽已经约定的最大亏损。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构例子选一种只向上收紧的多头版本：初始参考100，ATR为2，倍数3。

  1. 初始保护参考100−6＝94。
  2. 参考价格升到105且ATR仍为2，候选线为99，于是保护线由94抬到99。
  3. 随后参考104、ATR升为3，候选为95；因为本例规则只收紧，线仍留99，收盘98就穿线。

把观察连起来，你可以这样说

先确定规则才能理解线为什么动或不动；本例穿线代表原定保护条件被触及。

但不要跳到这个结论：并非所有ATR脚本都会把线留在99，图线也不保证99有实际成交。

最后试一题：你真的看懂了吗？

ATR从2变3，是不是应该把保护线往下挪，让价格多喘口气？

想好后，点开答案与解释

不能临时这样推导。ATR只是历史波动变大，是否可放宽要看原先规则；本例只收紧就不下移。先决定可承受损失，再观察指标，不能为了避免一次退出不断改口径。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

无可确认的单一创始人 / No verified sole inventor

ATR 由 J. Welles Wilder Jr. 提出，但“ATR跟踪止损”是多种后续算法的统称，不能把所有版本都归为 Wilder 首创。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：ATR Trailing Stop

通常通过社区脚本查找；核对作者、公式及实时是否重算，不保证内置同款。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：ATR跟踪止损 / ATR Trailing Stop

查找词，支持情况未确认；找到ATR本身不等于找到跟踪止损算法。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
