Choppiness Index 震荡指数

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

CHOP 判断价格是在原地来回折腾，还是比较顺地往一边走。值高更像横盘，值低更像有趋势，但不说方向。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

走了很多步却没离家多远，就是高 CHOP；一路直走，就是低 CHOP。

举个例子（虚构数字，只为讲解）

示例：价格在 100 到 102 之间来回，CHOP 可能很高；若持续跌到 90，CHOP 也可能变低。

先知道：为什么要看这个指标？

区分价格是在原地绕圈，还是比较顺地朝一边走。CHOP 高意味着走了许多弯路，低意味着同样路程中净推进较多，它不判断上涨或下跌。

什么时候看它比较有意义

在决定用趋势观察思路还是区间观察思路之前，先看行情环境；不要在它没有回答方向的问题上强行找方向。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方 CHOP 窗格的线与纵轴
读数常按 0 到 100 展示，无货币单位；61.8 和 38.2 是常见参考线，必须与所用周期一致理解。
主图最近同样数量的 K 线
观察每根来回波动的总路程，相对于整个窗口最高到最低的跨度有多大；来回走很多却没走远，CHOP 往往高。

第二步：看到变化，怎么读懂？

你看到：CHOP 高于 61.8 且维持高位

这说明什么：历史窗口更零碎、更曲折，追随方向容易被反复甩回。

还不能说明什么：不等于价格波动很小。

你看到：CHOP 降到 38.2 下方

这说明什么：价格路径更有方向，但方向要看主图。

还不能说明什么：不能把向下趋势误读为买入信号。

你看到：CHOP 从很低开始回升

这说明什么：原本顺畅的路径变得更曲折。

还不能说明什么：不保证趋势立即反转，也可能只是暂停。

最容易看错的地方

低值可能伴随上涨，也可能伴随下跌。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构两段行情：甲每天在 100 和 105 之间往返，CHOP=65；乙从 105、102、99 走到 96，CHOP=30。

  1. 甲虽有明显日内振幅，最终却不断折返，曲折程度高。
  2. 乙的价格在下降，CHOP 低描述的是路径顺畅而非利好。
  3. 乙后来横在 96 附近，CHOP 升到 45，说明趋势性开始减弱。

把观察连起来，你可以这样说

CHOP 用来选环境解释，不用来决定买卖方向；下跌也可以是非常低的 CHOP。

但不要跳到这个结论：65 不是跌 65% 的风险，30 也不是上涨概率。

最后试一题：你真的看懂了吗？

价格连续大跌，CHOP 从 60 降到 28，指标和价格矛盾吗？

想好后，点开答案与解释

不矛盾。价格越来越顺地向下走，所以曲折程度下降。方向在主图，CHOP 只描述路径。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Choppiness Index

TradingView 官方有对应指标说明，可先在内置技术指标中按英文名称查找。 常见 Length 14，保留零偏移；参考 61.8/38.2 只作环境观察。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：震荡指数 / Choppiness Index

尚未逐项核实 AiCoin 当前版本是否提供此指标。以下为搜索词，不保证搜得到；若有同名脚本，先核对公式与参数。 若找到对应实现：常见 Length 14，保留零偏移；参考 61.8/38.2 只作环境观察。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
