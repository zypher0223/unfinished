Bollinger BandWidth 布林带宽

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

把布林上轨和下轨的距离变成一个数字。数值小表示带子窄，近期价格比较安静；数值大表示带子宽，近期更活跃。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

不看整条伸缩道路，只量道路宽度的尺子。

举个例子（虚构数字，只为讲解）

计算示例：上轨104、下轨96、中线100，带宽=(104−96)÷100×100=8%。

先知道：为什么要看这个指标？

布林带宽BBW把上轨与下轨之间有多宽变成数字，常用(上轨−下轨)÷中轨×100。它专门看近期价格相对分散程度的大小，把‘市场安静还是闹腾’从涨跌方向里单独拿出来。

什么时候看它比较有意义

想在同一资产的历史中找异常安静阶段，或看波动是不是正在扩张时有用。先和它自己的过去比较：某个币平时带宽20%，股票平时3%，不能用同一条绝对门槛说谁都进入挤压。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

下方Bollinger BandWidth曲线与刻度
常见读数8表示8%，但有脚本用0.08表示同样比例，先确认显示规则。它主要非负，越高带子越宽，没有涨跌方向意义。
主图同参数布林带及过去几个月带宽
确保都用相同20期、2倍等参数。对照本资产历史低谷，看现在是否相对窄；不要仅凭视觉压缩的纵轴判断极端。

第二步：看到变化，怎么读懂？

你看到：BBW处于本资产历史低位

这说明什么：近期价格较集中，是相对安静状态。

还不能说明什么：不保证马上突破，也不指定突破方向。

你看到：BBW由低位持续上升

这说明什么：价格分散增大，波动正在扩展。

还不能说明什么：向下跌也会扩展，曲线上升不是价格上涨。

你看到：BBW高位回落

这说明什么：近期波动逐渐收敛，或旧的极端价格移出窗口。

还不能说明什么：不必然表示价格回调或市场见顶。

最容易看错的地方

带宽低不告诉你下一步涨还是跌；低也可以持续很久。不同资产不能共用一个固定低点标准。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构布林带中轨100、上轨104、下轨96，BBW=(104−96)÷100×100=8%。

  1. 之后上102、下98、中100，带宽缩到4%，近期价格更集中。
  2. 再后来中线98、上106、下90，带宽约16.33%，明显扩展。
  3. 这次中线还下降，所以波动变大伴随的是偏弱价格，不是上涨。

把观察连起来，你可以这样说

BBW只处理宽窄。看到它从4%增至16.33%，下一步应回主图找价格向哪个方向离开原范围。

但不要跳到这个结论：没有证明价格将继续向那个方向，也无法由带宽推算账户可获利多少。

最后试一题：你真的看懂了吗？

BBW从3升到9，但币价从100跌到90，是否矛盾？

想好后，点开答案与解释

不矛盾。BBW上升说价格分散和带宽扩大，剧烈下跌也会造成。把波动大小与上涨下跌分别写出来，才不会误读向上的指标线。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

John Bollinger

Bollinger本人官网说明，他在布林带之后增加了BandWidth；这里不采用互相冲突的二手首次年份，也不声称核实了首笔实盘。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Bollinger BandWidth

官方内置BBW；数值通常按百分比显示。 操作练习：添加Bollinger BandWidth，先用20期、2倍。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：BBW / BandWidth / 布林带宽

独立入口未核验；若只有BOLL，可先直接看上下轨距离，不能把它冒充精确BBW读数。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
