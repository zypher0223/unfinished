Keltner 肯特纳通道

我的学习与错题新手路线

记录仅保存在当前浏览器；已读不等于已经掌握。

现代肯特纳通道通常以EMA为中线，再向上下加减几倍ATR。ATR是近期每根K线通常能活动多大，包含跳空影响。

第一次看交易图？先认识这些词
K线、蜡烛图是什么？
一根像蜡烛的小图形，记录一段时间的开盘价、最高价、最低价和收盘价。选择“1天”，一根就是一天；选择“1小时”，一根就是一小时。
“周期/长度14”是什么意思？
通常是用最近14根K线来计算，不一定是14天。在1小时图上，就是最近14根一小时K线。
主图、副图在哪？
主图是显示价格的大图。副图是下面单独的一小块图，数字的单位可能和价格完全不同，不能直接比大小。
“信号”是什么意思？
只是一个值得留意的现象，例如两条线交叉了；不是保证涨跌，也不会因为你添加指标就自动下单。
趋势、动量、波动，有什么不同？
趋势看一段时间的大方向；动量看涨跌推进得快不快、有多用力；波动看价格折腾的幅度有多大。跌得很快可以是下跌动量强，绝不是只有上涨才叫强。
交叉、背离、确认是什么意思？
交叉是两条线穿过彼此；背离是价格和指标没有一起走出同样的新高或新低；确认通常是等这根K线结束或等后面几根走完，才能把现象认定下来。指标的标记画在过去，不代表当时就能看见。

把它想成生活里的东西

以平均路线为中心，按最近路况决定留多宽的安全边。

举个例子（虚构数字，只为讲解）

计算示例：EMA100、ATR2、倍数2，上下轨就是104和96。

先知道：为什么要看这个指标？

现代肯特纳通道通常以EMA为中线，以ATR的倍数决定上下距离。EMA代表平均方向，ATR代表近期每根通常活动多大，两者组合出随波动伸缩的范围。与布林带不同，它主要用真实波幅而非价格标准差定宽。

什么时候看它比较有意义

想同时观察平均方向和价格偏离是否相对近期波动很大时有用。沿上轨可以是强势延续，回中线可以是正常回调；先看通道斜率与价格是否持续在一侧，再理解碰轨的意义。

第一步：眼睛具体看哪里？

先找位置，再认单位；不同软件可能用不同颜色，认名称和含义比记颜色更可靠。

主图中EMA中轨与上下轨
例如中线20期、ATR10期、倍数2，三线都用价格单位。先确认宽度算法为ATR；同叫KC的变体可能用不同波幅算法，不能照搬数值。
上下轨间距与当前收盘位置
间距增大说明ATR扩大；它不表明涨跌方向。向左看多根的中线斜率，再看价格是否围绕中线来回，还是持续留在上半或下半。

第二步：看到变化，怎么读懂？

你看到：中线上行、收盘持续在上半带或上轨附近

这说明什么：平均方向偏强，近期价格也偏高于平均。

还不能说明什么：碰上轨不自动等于应卖或价格见顶。

你看到：带宽明显扩大，价格跌到下半带

这说明什么：波幅变大并伴随偏弱价格，要把波动和方向分开。

还不能说明什么：宽带不是价格上涨证据。

你看到：中线走平、价格反复穿越

这说明什么：平均方向不清楚，通道此时更像波动参照。

还不能说明什么：每次穿越中线都不是新趋势。

最容易看错的地方

它与布林带使用不同宽度算法；碰上轨既可能强势延续，也可能回落，不能单独下结论。

第三步：陪你完整读一次图

下面是虚构的读图练习，不是当前行情。重点是学会从看到的现象推导出合理解释。

虚构EMA100、ATR2元、倍数2，上轨104、下轨96。

  1. 收103在上半带，距中线3元，相当于1.5倍ATR。
  2. 后来EMA102、ATR3，上轨108、下轨96；收107仍在上半，且通道更宽。
  3. 下一根收101跌到中线下，不必然等于长期下跌；先观察后续收盘及中线是否转低。

把观察连起来，你可以这样说

同时读平均方向、波幅大小和价格相对位置，才知道同一根大波动在当前环境里有多突出。

但不要跳到这个结论：上轨108不是未来最高价，下轨96不是自动止损成交价，ATR倍数也不保证覆盖全部波动。

最后试一题：你真的看懂了吗？

肯特纳上轨和布林上轨同为104，能认为两个指标完全相同吗？

想好后，点开答案与解释

不能。这只是当时碰巧数值一致；一个常按ATR定宽，一个按标准差定宽。数据改变时宽度会不同，也不能把相关的两条带当完全独立预测。

能说清“看见什么 → 代表什么 → 还不能确定什么”，再去下面的软件操作部分照着练习。

是谁提出或推广的？

Chester Keltner；现代版本由Linda Bradford Raschke推广 / Chester Keltner; modern form popularized by Linda Bradford Raschke

Keltner于1960年书中介绍基础思路；Raschke推广EMA中线加ATR带宽的版本。不能把现代公式完整归为一个人的原版。

提出者、推广者和第一个实际使用的人是三回事。这里按可追溯资料写明，不把后来的推广者一律说成最早创始人。

手把手找按钮：TradingView 与 AICoin

以下按电脑网页版编写，依据 2026-10-19 查阅的官方帮助。手机App的入口位置可能不同，部分功能还受账号权限和数据源限制。

TradingView

本条目搜索词：Keltner Channels

官方内置KC；设置可选择不同宽度算法。 操作练习：添加Keltner Channels，确认Bands Style选ATR。

  1. 点击下面的 TradingView 按钮，打开网页版图表。左上角选要观察的股票或币种，并核对交易所；再选 1小时或1天等周期。1天表示每根蜡烛对应一天。
  2. 在图表上方找“指标 / Indicators”按钮，点开后使用搜索框。下面是本条目的搜索词：先试第一个，再试其他词。优先核对内置技术指标的名称；同名社区脚本可能用不同公式。
  3. 点结果名称即可添加；关闭搜索框，检查图上是否多了一条线或下方多了一个小图。没有同名内置结果时，先读下面的可用性说明，不要随便把相近指标当成同一个。
  4. 鼠标移到已添加的指标名称上，打开旁边的设置按钮。在“输入 / Inputs”里查看长度等参数；先保留默认值，再按本页阅读步骤观察。“样式 / Style”只改颜色和线条外观。
  5. 对照几段已经走完的历史价格，看看指标当时显示了什么；显示出来不等于平台会替你交易。先能解释图形，再考虑模拟练习。

AICoin

本条目搜索词：KC / Keltner / 肯特纳通道

官方文档列有基于ATR的Keltner通道。核对中线周期、ATR周期和倍数，再与本页示例比较。

  1. 点击下面的 AICoin 按钮进入网页版图表，选择交易所和交易对，例如某个交易所的 BTC/USDT；现货和永续合约的数据不同，要先看清名称。
  2. 在K线图顶部找“指标”，点击打开指标库。优先在搜索框输入下面的本条目缩写，再试中文名称；底部快捷栏也可能列出常用指标。
  3. 只有找到确切匹配的结果才添加。检查它出现在主图还是下方副图。名称相似不等于公式相同；以本页原理和结果的说明为准。
  4. 如果该指标提供参数入口，打开其参数/设置，先保留默认值；按本页步骤观察。若界面入口与此不同，按官方帮助核对版本，不要据此认为一定存在该指标。
  5. 搜不到时，不代表操作失败：本条目未必是当前版本的内置功能。可查看“自定义指标”中已有实现；没有能核对公式的实现时，改在支持它的平台学习。本页不会把猜测的按钮当成已确认功能。
